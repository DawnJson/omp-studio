# 4.8 UserMessage

**没有运行脊线**：对话列左侧不画竖线，也不给用户消息、过程行、结论画节点；`.turn` 不缩进，内容占满列宽，和输入框左缘对齐。

聊天式**右对齐**，短消息只占文字宽度；气泡无边框，右下角小"尾巴"（`direction-3.0.md` §3.3；样式在 `features/tsp/tsp.css`）。长消息收起成前几行 + 渐隐 + `N more lines`（§4.14「长用户气泡收起」，展开状态不记忆）。附件：文字上方一排靠右的缩略图，点击用系统默认查看器打开。hover 时气泡上方出现一行图标按钮：omp 自己的复制、回退（`omp.user.tools`），后面是 studio 加的编辑和分叉（§4.11，`layout.tsx` 的 `UserToolsRow`）；文字只在 `aria-label` / 悬停提示里。出现动画见 §2.6。

- 状态：默认 / 发送失败（错误 toast `msg.sendFailed` · 原因；清空输入框是乐观的，失败时草稿放回输入框，由用户重发——没有消息下方的失败行，也没有重试链接，`features/composer/actions.ts`）。运行中发出的消息：`Enter`（插话）由 omp 立刻作为用户消息上屏；`Ctrl+Enter`（稍后）进 omp 的排队（dock 里的 `omp.queue`），轮到时才上屏（`docs/architecture/tsp-real-omp-probes.md` §5）。
