# 4.28 子代理面板（右栏，TSP 任务，S1Agents；2026-10-21）

统计栏（`.agents-stats`）采用无底色上下细线收束：短指标（进度、费用、Token、请求、工具调用）单行等宽横排，上下文（`43% · 86K / 200K`）独立通栏并带细进度条，≥ 90% 切错误色（所有者定，2026-11-27）；值单行省略，悬停 `title` 是全文；列表行的名称、说明单行省略，悬停 `title` 是全文；窄面板里先省略类型、`后台` 这类标签，名字至少留 8 个字符（2026-10-29）。

代码 `features/agents/`（`AgentsPanel` 外壳 + `AgentRow` + `AgentDetail` + `SteerBox`，`agents-store.ts` / `agents-actions.ts` / `agents-slash.ts`，样式 `agents.css`），文案 `agents.*`。**不弹 omp 的 Agent Hub**：`👥` 胶囊、`/hub`、命令面板都打开这个面板。数据来源和后台驱动 Hub 的步骤见 `docs/architecture/subagents.md`。

**入口**：① hud 里 `👥 N agents running` 胶囊（omp 的 `omp.hud.seg`，点击动作 `agents.open`）——`tsp/actions.ts` 的 `runAction` 认出这个动作名（`shared/tsp/agent-hub.ts` 的 `isHubOpenAction`）就改开面板，**不把动作发给 omp**；② 命令面板 `子代理（查看、插话、结束、恢复）`（`agents`，只在 TSP 任务里列，再选一次关闭）；③ 斜杠命令 `/hub`（`tsp: "studio"`）；④ 后台任务弹层里子代理作业的“查看”（S2Jobs 调 `openAgentsPanel(taskId, name)`，打开并选中那一个）；⑤ 顶栏文件按钮右边的子代理按钮（`AgentsToggle`，`topbar-agents`，2026-10-22 起；只在任务里有，`toggleAgentsPanel`，子代理都结束、药丸左半段消失后仍能从这里打开）。面板和文件面板同一栏，**同一时间只开一个**：开子代理面板先关文件面板（`openAgentsPanel`），文件面板一打开 `App` 就收起子代理面板；Esc 或 × 关闭，焦点还给打开前的元素。只在对话页、且面板属于当前 TSP 任务时显示；宽度和文件面板共用（`usePreviewWidth`，默认约 36%，左缘拖动 / ←→ 调宽，最宽 70%）。

**布局**（`agents-panel`，外框沿用 `.file-preview`，其余样式都是 `agents.css` 里的 `agents-*` 类）：头部 = 页签（贴齐 40px 面板头底边，无悬空底线，同文件面板）+ 关闭 ×（`IconButton`，`agents-close`）。中间 `agents-body` 按页签分区：**子代理页**上下独立滚动（所有者定，2026-11-27）：上方列表区（`agents-list-zone`，上限约 36% 高度，少时自然收缩）+ 下方详情区（`agents-detail-zone`，均带 `ui-scroll-fade`），**插话框钉在面板底边**不随详情滚动。**列表**（`agents-list`，每行 `agents-row`，`data-name` / `data-status`）：左端状态点、名字、`后台` 小标签（类型只在不是默认的 `task` 时显示）；右端遥测集群（`agents-row-meta`）统一靠右排 Ctx、用时（`agents-row-time`，运行中按 omp 给的 age 本地每秒走，结束后是总用时；2026-11-08 仓库所有者定从详情统计挪到这里）和状态文字（运行中有完成度估计时换成进度环 + 百分比，`agents-row-progress`）；第二行是正在用的工具名（`agents-row-tool`）和意图，没有工具时是任务说明第一句（去掉 Markdown `#`）；运行中两次工具调用之间 omp 发 `tool: null`，第二行接着显示上一个工具，不跳回任务说明（2026-11-09 仓库所有者定）；右端状态 / 进度环最少占 `5em`、靠右，换成进度环时左边的用时不横跳；运行 / 等待中的排在前面；总有一行选中（没点过就是第一行，再点不取消），选中行中性 `--bg-active`（所有者定，2026-11-27，与左侧任务栏一致，选中行内标签换表面底保持层次）。**详情**（`agents-detail`，切换时 `ui-data-in` 轻淡入）：头部（`agents-detail-head`）左双行（上名字，下模型等宽 + `· 思考强度` + fallback 徽章）+ 右按钮组固定右上（`进入对话`、`结束` / `恢复`）；统计栏（`agents-stats`，无底色上下细线收束：单行短指标带 + 独立通栏上下文进度条；**费用和 token 折在详情里，不进列表行**）；下面三块（`任务`、`最终输出`、`对话记录`）用 `SectionHead`，块间极浅顶边细线分层：**任务**：omp 给的原文 Markdown 全文显示（次级正文色，`# Target` 等小标题同字号略加重）；**最终输出**（主正文对比度，来自 `<名字>.md`，无输出时不画）；**对话记录**（`agents-record`；标题是 `Disclosure`（`agents-record-toggle`），**默认收起**（2026-10-27 仓库所有者定），点开才读 `<名字>.jsonl`，展开时右端 `重新读取`）。**插话框**（`agents-steer`）：紧凑单行胶囊（所有者定，2026-11-27）：沿用 `.composer` 外框与 `.composer-field`（`agents-steer-input`，单行起自动增高到 6 行）+ 右端同排贴底对齐圆形发送键（`.send[data-kind="send"]`，`agents-steer-send`）。没有子代理时面板中间显示空状态 `agents.empty`（页签不写 0）。**历史子代理**：同一个 omp 进程里，之前回合的子代理（`done`）一直在列表里；`--resume` 恢复的会话里旧子代理显示为"已挂起"（可恢复，见 `docs/architecture/subagents.md`）。

**操作**（都是主进程在后台驱动 omp 的 Agent Hub，见 `docs/architecture/subagents.md` "后台驱动 Hub"）：**插话**（`SteerBox`：Enter 发送，Shift+Enter 换行，输入法组字时不发；运行 / 等待 / 空闲 / 挂起的子代理才有，已完成 / 被结束 / 失败的没有）、**结束**（运行中才有；omp 自己对 kill 没有确认框，所以点 `结束` 先弹 `Popover` 行内确认（`agents-kill-confirm`，`kind="confirm"`：宽 300、最小 280，右对齐、向下展开）：标题 `结束`、正文 `agents.killConfirm`（`结束 X？它正在做的事会被中止（之后可以恢复）。`），按钮 `不结束`（sm，打开时获得焦点）/ `结束子代理`（danger-solid sm，`agents-kill-yes`））、**恢复**（被结束或挂起的才有）。**驱动期间**（`useTspDrive`，调 IPC 前后）面板顶部出现一条 `agents-driving`（`role="status"`，`data-op` = steer / kill / revive，`data-name`）：`正在发给 Beta…` / `正在结束 Beta…` / `正在恢复 Beta…` （2026-10-24 起没有第二行小字说明）；面板里所有操作按钮和插话框此时停用。**omp 的 Hub 不画出来**（`TspView` 的 layer 区在驱动期间不渲染 picker），过程区压暗且不可点（`.tsp-surface[data-driving]`，`opacity: 0.45`；聚焦模式里过程区暂时是那个子代理的记录，不能当成主对话）；`useTspPanelOpen` 在驱动期间不把这个 Hub 当“面板开着”，主输入框照常可输入——此时发出的消息主进程让它等驱动结束再发到主会话，**不会变成对子代理的插话**。结果用一条 toast（`已发给 Beta` / `已结束 Beta` / `已恢复 Beta`），失败用 `reportOmpError` 带 omp 的原文（例如恢复运行中的子代理时 `Only parked or killed agents can be revived`），插话失败时文字留在框里。

**进入对话（聚焦，2026-10-23；2026-10-26 起只从详情头部进）**：照 omp Agent Hub 里 `Enter` = 聚焦那个子代理的会话。**点列表里的一行只选中它**（详情在列表下方展开，当前详情的行整行高亮，`li.agents-item[data-current]`，同 omp Hub 里移动光标），不切过去（仓库所有者 2026-10-26：点行就跳进对话不对，点"进入对话"才跳）。详情头部（`agents-detail-head`）最左的按钮 `进入对话`（`Button` primary sm，`agents-focus`，之后才是 `结束` / `恢复`）= 聚焦（`focusAgent`，IPC `focusTspSubagent`）：主进程在后台 `agents.open` → `activate`，等聚焦行出现，**不恢复**主输入框（留在聚焦模式）；成功后面板收起（`closeAgentsPanel(false)`，露出过程区）、焦点回 studio 输入框，不弹 toast——输入框上方的聚焦提示（`run-focus`，`正在给 Beta 发消息` + `回到主会话` `run-focus-back`，§4.14）就是反馈和出口；之后输入框发的话走普通 `sendPrompt`（omp 把它 steer 给子代理）。驱动期间沿用 `beginTspDrive` / `endTspDrive`（`agents-driving` 的 `data-op="focus"`，显示 `正在切到 Beta…`，不显示"完成后自动恢复主输入框"那行小字；omp 的 Hub 一帧不画，过程区压暗）。失败（omp 没切过去、行里的子代理 omp 的 Hub 没列出等）：按恢复规则关 Hub，toast 带 omp 的原文，面板留着。**哪些状态有"进入对话"**：`running / idle / parked / aborted`（`canFocus`；实测 omp 18.12.6 的 running 和 aborted（聚焦即复活）能进，见 `docs/architecture/subagents.md`「聚焦」）；`pending`（omp 的 Hub 里还没有这一行，实测聚焦报 `Alpha is not listed in omp's Agent Hub`）和 `done / failed` 没有。聚焦期间 omp 在主界面画的是子代理自己的会话，文档里没有 `agent` 节点（实测），所以面板的列表是空的，面板里什么都不写（原因输入框上方的聚焦提示已经在说）；插话 / 结束 / 恢复此时按「不是文档里的子代理」拒绝，回到主会话后恢复。Activity 页点一行仍是回 Agents 页选中那个子代理（看详情）。

**列表的数据**直接来自 TSP 文档（`shared/tsp/agent-hub.ts` 的 `listAgents`：task 工具卡片下的 `agent` 节点，按名字去重取“更活”的；卡片已结束而节点还写着等待 / 运行的当作挂起），渲染进程用 `useTspDerived` 推导，随 omp 的帧实时更新，**不需要 IPC**；记录和最终输出经 `getTspSubagentRecord(taskId, name)`（主进程只读会话目录里的 `.jsonl` / `.md`，名字限 `isAgentName`、路径必须落在会话目录内，读不到给 `unavailable` + 原因，界面显示原因不吞错）；三个操作经 `steerTspSubagent` / `killTspSubagent` / `reviveTspSubagent`（渲染进程只传任务 id + 名字 + 文字，名字必须是文档里确有的子代理）。

**降级**：omp 改了 Hub 的 role / action 名（`agents.open`、`kill`、`revive`、`omp.composer.focus`、`focus:Main`）时三个操作超时失败，主进程照样走恢复（Esc 关 Hub、退出聚焦），恢复不了才以明确错误抛出；列表、详情、记录不依赖 Hub，不受影响。

**可访问性与动效**：面板 `aria-label`，列表项是真按钮（`aria-current` = 选中），`agents-driving` 是 `role="status"`；驱动横幅的圆点呼吸动画沿用 `--play-state`（减少动效时静止）。

**页签、Activity 页和 Ctx**：面板头里的 `ui/Tabs`（`agents-tabs`：`agents.tabAgents`（带个数）/ `agents.tabActivity`；页签状态是面板自己的，关面板后回到 Agents 页）。**Activity 页**（`AgentsActivity`，`agents-activity`）：所有子代理的活动按时间从新到旧排成一条流，数据来自 `<名字>.jsonl`（`shared/tsp/agent-activity.ts` 合并，最多 500 条）；顶部过滤分段（`Segmented` sm，`agents-activity-filter`：`all / errors / responses / tools`）顶置固定，下方独立滚动区（`agents-activity-scroll`，带 `ui-scroll-fade`）内每行（`agents-activity-row`，`data-kind`、`data-agent`、`data-failed`）采用双行紧凑条目（所有者定，2026-11-27）：上行子代理名 + 种类标签左对齐、时间（`HH:mm:ss`）右对齐；下行占满整行宽度展示工具名与摘要（最多两行省略，出错行红字）；点一行 = 回到 Agents 页并选中那个子代理。没有活动时显示 `agents.activityEmpty` / `agents.activityNone` / `agents.activityLoading`。**Ctx**：`agent` 节点的 `stats.context` 解析成 `HubAgent.stats.context`；列表行右端遥测集群里细条 + 百分比（`agents-row-ctx`，≥ 90% 换错误色），详情上下文进度条显示 `43% · 8.1K / 1M`。
