# 4.29 浏览器面板（右栏，任务）

代码 `features/browser/`（`BrowserPanel` + `BrowserToggle`，`browser-store.ts`，样式 `browser.css`，外框沿用 `.file-preview`），文案 `browser.*`。页面本身是主进程的原生视图（`WebContentsView`），叠在占位区上；它同时是这个任务的 omp `browser` 工具用的浏览器。主进程、CDP 转接和插件见 `docs/architecture/browser.md`。

**入口**：顶栏子代理按钮右边的浏览器按钮（`topbar-browser`，只有任务有）、`Ctrl Shift B`（§5.1）、命令面板 `浏览器`；再按一次关闭。**omp 连上这个任务的浏览器时自动打开**（当前任务才开），不抢输入框的焦点。面板和文件面板、子代理面板同一栏，**同一时间只开一个**（`openBrowserPanel` 关另外两个；另外两个打开时 `App` 收起它）。Esc（焦点在面板头部时）或 × 关闭，焦点还给打开前的元素。宽度和文件面板共用（`usePreviewWidth`）。关闭只是藏起页面：页面、登录状态、omp 的连接都留着，再打开还是那一页；任务归档 / 删除时页面才销毁。

**布局**（`browser-panel`）：头部 = 后退 / 前进（不能走时停用）、刷新（加载中变停止，图标形变（§2.6）；没打开过页面时停用）、地址栏（`browser-address`）、关闭 ×。
- 地址栏：用户打开面板、还没有页面时焦点直接进地址栏（omp 连上自动打开的不抢焦点）；没在改时跟着页面地址走，改了没回车保持用户的字；回车打开：http/https 原样，`localhost` / `127.x` 补 `http://`，像域名的补 `https://`，其余当搜索词交给 Bing，别的协议不打开。
- 下面是占位区（`browser-view`），页面视图盖在上面；占位区左边让出拖拽条的宽度（页面盖不住拖拽条，整条左缘都能拖），主进程给页面 `setBorderRadius`，页面不压住面板的圆角描边。新页面是 `about:blank`，地址栏留空。

**浮层**：页面是原生视图，会挡住应用里的浮层。遮罩弹窗开着、或菜单 / 下拉 / toast 这类挂在 body 下的浮层压到占位区时页面藏起来，浮层关掉后回来。自绘的悬停提示（`role="tooltip"`）不藏页面（每次悬停都藏会闪），所以头部带 `data-tip-side="top"`，提示画在头部上方。

**限制**：只有一个页面（链接的新窗口在原页面打开）；omp 关不掉这个页面；没有开发者工具。
