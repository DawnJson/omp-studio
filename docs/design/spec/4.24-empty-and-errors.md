# 4.24 空状态与错误汇总

| 场景 | 呈现 | 恢复动作 |
|---|---|---|
| 侧栏无任务 | `sidebar.empty` | — |
| 搜索/面板无结果 | `palette.noResults` | `palette.askNew` |
| omp 进程意外退出 | 侧栏该行变错误态（`shared/ui/sidebar-model.ts`）；某个操作因此失败时弹错误 toast `error.exitedNoCode`（`TaskError.kind` 由 `shared/ui/errors.ts` 映射）。没有对话流末尾的内联条，也没有“重新连接”按钮。留下的对话（和主动关掉的 stopped 任务一样）不再像在跑：还在跑的工具卡画成已取消（同 `/jobs kill`）、子代理行画成已中止，计时停在进程结束那一刻，循环动画暂停（`TspView` 的 `data-ended` + `TspEndedAtCtx`） | — |
| 协议错误 | 同上：toast `error.protocol` | — |
| `prompt` 被拒 | 错误 toast：`msg.sendFailed` · 原因；草稿放回输入框（`features/composer/actions.ts`） | 用户重发 |
| 模型不可用 | 恢复任务时模型不可用：toast `error.modelUnavailable`（`TaskError.kind` = `restore_model_failed`）；没有内联条 | — |
| 本轮以错误结束（含模型返回错误） | 对话末尾 omp 自己的错误卡（`omp.error`；dock 里重复的错误横幅不画，`shared/tsp/error-turn.ts`） | `sessionInfo.retry.button`（发 `/retry`；只在末尾那张错误卡且任务空闲时出现，`RetryButton.tsx`） |
| 工具失败 | 工具卡片显示失败状态（omp 的节点，studio 照画） | — |
| 项目目录 / 工作区不存在 | 从历史恢复会话时目录已不在：toast `history.resumeFailed`（`TaskPool.resume` 先 `stat` 目录，不替用户迁移会话）；worktree 任务的工作区被删：输入框禁用，占位 `error.worktreeMissing`（`Composer.tsx`） | — |
| 会话文件被删（在 omp 的会话列表里删的） | 启动后、窗口回到前台重扫会话时对账（issue #10）：没归档、没有进程、不是选中的任务、没有 worktree、文件确实不在（`ENOENT` / `ENOTDIR`，隔一会儿再确认一次）的任务记录直接去掉，侧栏那一行消失，不提示。没去掉的（选中的、有 worktree 的）打开时不起 omp（`--resume` 会让它报错退出），任务状态 error；输入框不禁用，占位 `error.sessionMissing`，发消息就在这个任务里开新会话（issue #8；`docs/architecture/task-model.md`） | — |
| 渲染层崩溃（`render-process-gone`） | 只写日志（`main/log/instance.ts`），没有自动重载窗口，也没有 toast | — |
| 渲染层未捕获错误 | 没有全屏错误页，也没有错误边界 | — |

错误文案原则：说发生了什么、数据有没有丢、下一步按什么；不显示堆栈（堆栈只在“复制详情”里）。
