# 4.3 FolderGroup（文件夹头）

- 尺寸、颜色见 `features/sidebar/sidebar.css`。文件夹名（重名时 `上级/名称`，tooltip 完整路径），名称后面紧跟箭头（仓库所有者定，2026-10-27；展开朝下、折叠朝右；`flex: none`，名称太长被省略时箭头不被挤掉）。
- 右侧常驻一个 `＋`（`sidebar-project-new`）：在这个文件夹新建任务；studio 项目直接开草稿，只在历史会话里出现的文件夹先由主进程 `ensureSessionProject`（按会话 id 查 cwd，加成项目但不建任务）再开草稿。
- `＋` 左边一格（不看悬停）：**折叠时是行数**（组内有等待任务时前面加菱形；没有等待、有跑完还没看的任务时加绿色小圆点 `sidebar-folder-unread`，和行上的同色同形，2026-11-11），**展开时是 `⋯`**（`sidebar.projectMenu`），两者叠在同一格切换；名称始终让出这两格，展开折叠时不跳。**只有 studio 项目的文件夹才有 `⋯`**，纯历史文件夹展开后这一格是空的（右键也没有菜单）。
- 项目菜单：`project.reveal`（打开这个文件夹本身，不是上一级）、`git.menu.cleanup` 清理无主 worktree、分隔线后 `project.remove` 从列表移除（issue #9）：只把项目藏起来（`Project.hidden`，记在 `tasks.json`），不要求先归档，任务不归档、在跑的照跑；文件夹连同里面的任务和同一目录的历史会话从侧栏、命令面板、选项目、设置的作用域里一起消失；再用"打开文件夹"打开它、在里面新建任务或恢复会话时重新显示。
- 展开规则见 §4.5。展开后先显示几行，`sidebar.showMore` 每次再多一批（数量见代码）。
- 键盘：列表整体一个 Tab 停靠点（roving tabindex），`↑↓` 移动，`←/→` 折叠/展开，`Enter` 打开，`Home/End`；`Alt+↑/↓` 把文件夹上下移一格。
- 拖动：拖头部换位置，被拖的文件夹变淡，落点文件夹的上边或下边画一条 `--accent` 插入线；规则见 §4.5。
- 空项目（展开后没有任务和会话）：一行 `sidebar.empty`。
