# 4.26 TerminalPanel（内置终端）

入口：顶栏右端的终端图标按钮（`aria-pressed` = 面板开着）、`Ctrl \``、命令面板 `切换终端`。在对话页出现：任务页和新任务草稿页都有（草稿页顶栏只有终端按钮，没有分支/评审工具）；设置页不显示。实现在 `features/terminal/`，样式只用 token，主进程一侧见 `docs/architecture/terminal.md`。

- **位置**：主区面板最底部（输入框下方），上边缘压一条拖拽条。面板打开时对话区只是变矮：吸底时继续吸底，没吸底时阅读锚点不动（面板高度变化走和窗口缩放同一套 `ResizeObserver`）。
- **高度**：默认、最小、最大（主区高度的比例）见代码；窗口变矮时渲染时重新夹取，最小值优先；和旁路提问、输入框一起放不下时终端再让出高度，输入框不被挤出主区（§4.14「小窗口」）。拖动中只改内存，松手写进外壳状态（`terminalHeight`，和侧栏宽度同一处持久化）；拖拽条获得焦点时 `↑ / ↓` 调整，双击恢复默认。
- **头**：终端图标、shell 名（如 `pwsh.exe`）、目录最后一段（悬停显示完整路径）、右侧 `重启终端`、`隐藏终端`。`隐藏` 只收起面板，shell 继续在主进程里跑；`重启` 结束当前 shell 并在同一目录新起一个。
- **正文**：xterm.js（DOM 渲染器），颜色、字体取 token；ANSI 16 色从语义 token 推，黑/白两端随主题翻转，`minimumContrastRatio` 4.5。设置里切主题或系统深浅色变化时重新读 token。
- **打开**：每个任务一个终端；面板按任务记开关（切到别的任务再回来仍是开着的，接着原来的 shell；重启应用后默认收起）。用户主动打开时焦点进终端，切换任务时挂载的面板不抢焦点。目录（worktree 根或项目目录）已不存在时在终端区显示一句错误，按任意键重试。
- **草稿的终端**：新任务草稿也能开终端，目录是草稿项目的目录（没有项目时是 chats 目录）。发出第一条消息创建任务时，草稿的终端（同一个 shell、同一份屏幕）连同面板的打开状态交给新任务；开了 worktree 的任务目录不同，草稿的终端被关掉，任务的面板重新起。草稿切换项目时关掉上一个项目草稿的终端。
- **退出**：shell 自己退出时终端里追加一行灰色提示 `[进程已退出，代码 N] 按任意键重新启动`，按任意键在同一目录重新启动（新屏幕）。
- **键盘**：终端聚焦时按键归 shell（包括 `Esc` 和 Ctrl 组合键，不冒泡成全局快捷键）；例外：`Ctrl \`` 回到输入框并收起面板，`Ctrl C`（有选区时）和 `Ctrl Shift C` 复制，`Ctrl V` / `Ctrl Shift V` 粘贴。没有选区的 `Ctrl C` 照常是 `^C`。
