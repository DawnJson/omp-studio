# 4.7 EmptyState

- **输入框贴主区底部**，空状态和对话中同一位置。输入框上方是新任务页的概览（仓库所有者定，2026-10-27；`features/empty/EmptyState.tsx`、样式 `empty.css`），列宽同对话列，两块内容**在输入框上方剩下的空间里竖直居中**（`justify-content: safe center`）。概览比窗口高时整个 `.empty` 滚动（`safe` 保证不从顶上被切掉），输入框（`.empty-draft`）`position: sticky; bottom: 0` 始终贴底；sticky 建的层叠上下文层级照输入框给，否则弹出菜单会被盖住。**没有欢迎语、插画、示例提示卡**；不画 `omp studio` 字标（顶栏已有品牌）。
  1. **标题行**（`.empty-head`，两列网格）：左边像素 π（`EmptyMark.tsx`，装饰，`aria-hidden`；不用 `crispEdges`：高度不是 π 像素的整数倍，取整会让半像素的 ▒ 忽粗忽细），右边 `h1` `empty.title`。最近更新（见下）在第二行、第二列，和标题左对齐，不在 π 下面。
  2. **本周用量卡片**（`UsageCard.tsx`，`empty-usage`）：近 7 天（含今天）的 token 合计 + 同期费用（`formatCost`），右边一个“今天”小标签；下面是点阵（`role="img"`）：近 `OVERVIEW_WEEKS` 周每天一列，最后一列是今天；每列最多 `MAX_DOTS` 个点从下往上亮，亮几个 = 当天 token ÷ 这段时间里最多那天，按比例四舍五入，有用量的日子至少 1 个；SVG 按比例铺满卡片宽，点保持圆。较早的日子、最近 7 天、今天三档颜色。算法在 `usage-overview.ts`（纯函数），“今天”取热力图的 `to`（主进程按本地时区算的最后一天）。数据是 `getUsageHeatmap`，和用量对话框共用 `composer/usage-store.ts` 的缓存（`docs/architecture/omp-usage.md`）。
     - 还在读：数字位置是一条灰条（`role="status"`），点阵全空，不显示“今天”标签。omp 还没建过统计库（`hasDatabase` 为假）：只写标签 + `empty.usageNoDatabase`，不编数字。读失败且没有缓存：整张卡片不显示。
- **项目标签在输入框工具行里，审批胶囊右边**：`empty-project` = 文件夹图标 + 文件夹完整路径（不写项目名；太长时省略开头、留住末尾的文件夹名：外层 `direction: rtl` + 里面 `<bdi>`），纯文字、不画成胶囊，悬停提示完整路径。**只显示、不能点**：换文件夹走侧栏（`新任务` = 默认文件夹，文件夹头 `＋` = 那个文件夹，`打开文件夹` = 新文件夹）或拖入文件夹。项目目录正好是 git 仓库根时，顶栏右侧有草稿的分支胶囊，可勾选在 worktree 里开始（§3.1）。发出第一句话后任务的输入框在同一位置显示任务的工作目录（`composer-folder`，有 worktree 时是 worktree 根）。
- **默认文件夹**：新任务（侧栏 `新任务`、`Ctrl N`、启动时）一律在默认文件夹 `AppInfo.chatsDir`（`~/omp-studio/chats`）里，不沿用最近用过的项目，打开就能直接发送（同 Codex / Claude Code）。工具行标签写它的完整路径（侧栏文件夹标题才写 `empty.defaultFolder`）。第一次发送时主进程 `ensureChatsProject` 才建目录并加入项目，之后它在列表里是普通项目，但界面上一律叫"默认文件夹"。默认文件夹不是 git 仓库，没有 worktree 选项。不用用户主目录作 cwd：omp 默认会把主目录换成临时目录（`--allow-home`），搜索也会扫整个主目录。要在别的文件夹里工作：侧栏 `打开文件夹`、文件夹头的 `＋`、`Ctrl Shift N`（当前任务的项目）或拖入文件夹。
- 最近更新（照 omp 的 What's New，`startup.changelogMode = summary`；`features/empty/WhatsNew.tsx`）：升级后第一次启动时，标题下面一行，**只说一遍**、只写统计不列条目：`empty.whatsNewUpdated`，跨多个版本时 `empty.whatsNewUpdatedMany`；悬停提示是新增 / 变更 / 修复各几项（为 0 的省略）。不换行，窄了省略号截断。显示几秒后淡出，淡出后位置留着、下面的卡片不跳；这次启动里再进新任务页不再出现。数据来自打进主进程包的 `CHANGELOG.md`（`src/main/whats-new.ts`，解析在 `src/shared/changelog.ts`）：合计 `userData/last-changelog-version` 记的版本之后、当前版本为止的各节（没有记录 = 第一次装，只算当前版本；不含"未发布"），启动时算一次并立即写入当前版本，所以重载窗口仍显示、重启后消失；当前版本没有条目时不显示。
- 侧栏 `新任务` 按钮在草稿页带 `aria-current="page"`，用选中底色突出（§4.5）。
