# 4.32 桌面宠物

代码在 `src/renderer/src/pet/`（单独的 `pet.html` 窗口），样式 `pet.css`，文案 `pet.*`。窗口、状态、成长、说话的规则见 `docs/architecture/pet.md`。

**宠物**：16×16 的像素图，按每格 5px 放大，用 `crispEdges` 渲染，站在窗口底边正中。底图是物种 × 阶段（`shared/pet/sprites.ts`），用物种自己的固定颜色，不随主题变。

- 眼睛：画在 `e` 格上，表情决定眼睛的画法，样式来自骨（点、竖长、半睁、带高光）。
  - 出错是 X 形。
  - 跑完一轮是 ^ 形。
  - 等你确认时睁大，带一个高光点。
  - idle 和 running 每 4 秒眨一次眼。
- 帽子：戴在头顶最上面一行的正中，蛋没有帽子。光环浮在头顶上方两格。
- 头上的小标记：
  - 等你确认是 `--st-waiting` 色的 "!"。
  - 在跑是汗珠。
  - 出错是一朵小乌云，带一滴 `--st-error` 色的雨。
  - 跑完一轮是两颗星。
  - 空闲没有标记。
- 动画都是 3 帧的 `steps`，只上下动、不左右晃（仓库所有者 2026-11-11 定）：空闲时慢慢上下浮动，在跑时浮动得快，等你确认或刚跑完时蹦跳，出错时往下一沉；蛋和其他阶段一样跟着表情走。闪光（shiny）的宠物色相循环变化。减少动效时（系统设置或应用设置）所有动画停在第一帧。
- 装饰（`decor.ts`）：完全体以后每 10 级解锁一件，攒着不换掉。Lv40 左脚边一朵花，Lv50 右脚边一个蘑菇，Lv60 左上方一只上下飘的蝴蝶，Lv70 脚下一片草丛（画在身体后面），Lv80 左边一颗一闪一闪的星星，Lv90 身体外面描一圈金边，Lv99（满级）金边变成流动的彩虹色。

**彩纸**（`pet-confetti`）：成就（待办阶段做完、目标完成、开了 PR）时从宠物头顶往两边抛出 8 片小方块再落下，2 秒内淡出。

**交互**：宠物身上 `cursor: grab`。

- 按住拖动。
- 单击：摸一下，冒三颗依次升起的爱心。
- 双击：打开 studio。
- 右键：系统菜单。

**气泡**（`pet-bubble`）：在宠物头顶上方，用 `--bg-overlay` 底色、1px `--border` 边框、`--radius-lg` 圆角、`--shadow-1` 阴影，底部有个尾巴指向头顶。宽度随文字变化，最宽为窗口宽度减去边距。停留 5 秒，每多一个字加 60ms，最长 12 秒；点一下就消失。属性卡开着时不显示气泡。宠物窗口里的浮层（气泡、属性卡、确认框）都只用 `--shadow-1`，不用 `--shadow-modal` / `--shadow-2` 这类大模糊阴影：透明窗口直接盖在桌面上，大阴影会在下面留一片灰雾（2026-11-11 所有者截图）。

**升级 / 进化提示**（`pet-badge`）：头顶上一个 `--accent` 底色的胶囊，写 `Lv N` 或新阶段的名字，3 秒内一边上升一边淡出。

**属性卡**（`pet-card`）：在宠物上方，和气泡同一种外壳，左右离窗口边 8px。打开方式：右键菜单、`/pet`。关闭方式：点 ×。

- 第一行：名字按钮（宽度随名字，太长时省略号截断；点击后原地变成输入框，占满剩余宽度；Enter 保存，Esc 或失焦取消；名字不合法时边框变成 `--st-error`，悬停提示 `pet.renameInvalid`），后面紧跟星数和稀有度（稀有、史诗、传说各用自己的颜色）、物种、闪光的宠物再加 `pet.shiny`（`--fs-xs`、`--text-2`，不换行），× 靠右。还没孵化好时，名字位置显示 `pet.hatching`。名字和稀有度同一行（仓库所有者 2026-11-11 定）。
- 第二行：阶段 · `Lv N` + 一条经验进度条（`--accent`）。满级时名字前加一颗金色 ★。
- 第三行（`--text-2`）：陪伴天数（有动静的天数），连签超过 1 天时后面加 `· 连签 N 天`。
- 五项属性：标签、进度条、数值。进度条里出生值用 `--text-2`，成长出来的部分接在后面，用 `--accent`。
- 最下面是性格（`--text-2`），没有性格就不显示这一行。
- 卡片里不加任何说明文字（2026-10-28 定的"不写多余的字"）。

**重新孵化确认框**（`pet-rehatch-confirm`）：右键"重新孵化…"后在属性卡的位置弹出，和 studio 的 `ConfirmDialog`（§4.23）同一套样式：`.ui-dialog` 外壳、标题 `pet.rehatch.title`、说明 `pet.rehatch.body`、页脚"取消"在前、`danger-solid` 的"重新孵化"在后，没有 ×。宽度贴着窗口左右各 8px，标题区和页脚的左右内边距收到 `--space-5`（窗口只有 260 宽）。打开时窗口临时可聚焦，焦点在确认框本身（右键是鼠标操作，按钮上不画焦点环），Esc 取消；属性卡和确认框同时只开一个。不用系统对话框（仓库所有者 2026-11-11 定）。

**设置**：设置 → 通用 → 「桌面宠物」组：两个开关，显示宠物（`setting-pet-enabled`）、说话（`setting-pet-talk`）；下面两行只读的花费，今天（`setting-pet-spent-today`）和累计（`setting-pet-spent-total`），格式 `N 次 · 12.3K token · $0.0040`（`formatCount` / `formatMoney`），打开设置页时读一次，宠物没启动过时不显示。花费放在设置里，不放属性卡（仓库所有者 2026-11-11 定）。气泡是"不写多余的字"的例外：每句话都是宠物这个功能本身，用户可以关掉（仓库所有者 2026-11-11 定）。
