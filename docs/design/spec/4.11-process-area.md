# 4.11 过程区（TSP 节点）

对话里 omp 的工作过程（工具卡片、思考块、子代理卡片、待办、压缩分隔、每轮用量脚注）都是 omp 发来的 TSP 节点，由 `features/tsp/` 渲染：结构由 omp 决定，外观由 `features/tsp/tsp.css` 决定（见 §4.14 末尾"过程卡片外观"和 `docs/architecture/tsp-migration.md` §8）。折叠 / 展开跟着节点的 `collapsed`。

- **连续的工具调用合成一组**（issue #9 照 ompweb，仓库所有者批准，2026-11-09；设置 → 通用 `groupToolCalls`，默认开）——唯一由 studio 自己折叠的地方：两张及以上连着的工具卡（中间只隔着空的或只有思考块的助手列）前面插一行组头 `.tsp-run-head`（同收起的工具卡）：每种工具一个小图标 + 调用次数（种类多了合成 `+N`）、整组用时（各卡 omp 报的 `took` 之和）、有失败时 `N failed`、状态、箭头；悬停每张卡一行 `<标题> <目标> · <用时>`（仓库所有者选，2026-11-10）。跑完收起，有卡在跑或这一组在对话末尾且任务在跑时展开；子代理等待卡、提问卡不进组、打断一组；`Ctrl O` 后 omp 报工具输出展开着时全部组展开、收起时回到默认（`docs/architecture/conversation.md`）。
- 卡片本身的折叠没有例外：派子代理的 Task 卡片（`omp.tool.task`）omp 发成收起，studio 照画；子代理的进度在下面等待卡片（`omp.tool.wait`）的磁贴上，omp 发的 `preview:"children"` 让磁贴收起时也一直显示（仓库所有者定，2026-10-22）。
- **只显示标题**：设置 → 通用 `settings.toolHeadsOnly`（默认关，issue #8 用户请求）打开后，收起的工具卡只画标题行、不画预览；wait 卡除外（它的预览就是后台作业磁贴）。没有 `target` 的卡片在预览被藏掉时补一行 omp 已给的摘要（`command` 第一行，没有命令时是 `intent`；和标题相同就不补；展开后不补），否则 bash 卡只剩 `Bash` 两个字（issue #9，`nodes/work.tsx`）。
- 用户点开 / 收起一张卡后本地先记着，omp 发来不同的 `collapsed`（回显这次点击、`Ctrl O`）就作废本地记录，之后完全跟着 omp（`use-fold.ts`）；本地记录不作废的话，点开过的卡 `Ctrl O` 收不起来。
- eval 卡片的输出被 JSON 视图切成几段时，收起时合成一段只露末尾几行 + `N earlier lines`（`docs/architecture/conversation.md`）。`Ctrl O` 展开或收起所有工具卡片。
- 完成的工具卡标题行右边常驻一个淡色 ✓（issue #9 照 ompweb），跑完的那一次是转圈的弧形变成 ✓（失败 ×、取消 ⊘，§2.6 图标形变）。
- 运行状态、用时和当前活动在输入框上方的状态行（`ComposerTop`，§4.14），子代理在右栏的子代理面板（§4.28）。没有改动卡片：评审入口是顶栏评审按钮、提交对话框、`Ctrl Shift D` 和命令面板（§4.25）。

**bash 卡片的命令区**（omp ≥18.17 声明了 `shell` 后发 `shell` 节点，`nodes/shell.tsx`；没有 trace 的命令仍是 `code`）：按 omp 算好的行画，不自己解析 shell。每行 = 状态槽（失败 `×`、运行中 `▶`）+ 按 depth 的缩进 + 正文，折行时续行悬挂在缩进之后。配色照 omp 的 ANSI 渲染器映射到 `--syn-*`；chip / badge（重定向、内联脚本）是小药丸，两头的空格不包进去。运行中不在执行的片段变淡、执行中的片段加粗，不打成功勾。失败片段前一个 `×`（同一个命令只一次），行尾 meta（`exit 1`、`312ms`、`↻ 3`）；变量注释 `‹ name = "value" ›` 跟在设它的行后。effects 图标（网络、写文件、删除…）在正文前，**中性色，危险操作也不标红**，悬停是 omp 的 `label: why`（仓库所有者定，2026-11-10）。**Pseudo | Raw** 是第一行右端常显的 `ui-seg` 两段（omp 规范：开关留在第一行，不是悬停才出现），选中态只跟 omp 回来的 `preferences.view`，默认 Pseudo；文字是 omp 的叫法，不翻译。折叠块（如 `+1 more`）可点，悬停是全文，点了 omp 展开。折叠着按 omp 的 `preview` 行数夹紧，下面 `N more lines`（同 `code`）。图层菜单、split、回放不做。复制命令、"只显示标题"、合组读卡片头，不受影响。

**用户消息上 studio 的按钮**（`layout.tsx` 的 `UserToolsRow`，悬停 / Tab 到时和 omp 的复制、回退图标一起显示，键盘可触发）：omp 的图标后面依次是①**编辑**（仓库所有者批准，2026-11-09；`tsp-user-edit`）：把这条消息的文字放进输入框、焦点给输入框，改完自己发；**不回溯，对话不变**（仓库所有者定，2026-11-09：编辑是省得重打，不该删记录；要回到这条消息之前用会话树）；②**分叉**（`tsp-user-fork`）：从这条消息之前分出新任务。两者只在任务空闲时能点（否则 `aria-disabled`）。细节见 `docs/architecture/session-tree.md`。
