# 4. 组件通则

- 所有可点击元素有 `:hover`、`:active`（无位移）、`:focus-visible`、`:disabled` 四态（token 和取值在 `styles/` 与 `ui/controls.css`），下文各节不再重复。禁用色在卡片底上也要认得出，同时明显淡于 `--text-3`。
- **焦点环只给键盘**：全应用按最近一次输入判断（`ui/input-modality.ts` 在 `<html>` 上写 `data-input`，按下非修饰键算键盘、按下指针算鼠标，启动时算鼠标）；鼠标时 `--focus-ring` 透明，所以打开对话框这类程序放的焦点不画环，按一下 Tab 才画。悬停提示、平时藏着的工具行等「只给键盘焦点」的显示一律用它的 `keyboardFocused`。`--focus-ring` 只给 `:focus-visible` 用，omp 选择面板里的选中框等用 `--accent`。
- 输入类容器用 `:focus-within` 画焦点环（`ui/controls.css` 的 `.ui-field`；侧栏搜索框也是 `TextField`，没有例外）。
- 侧栏、按钮、标题栏 `user-select: none`；对话区全部可选。
- **选中即复制**（设置项 `copyOnSelect`，默认开；`app/use-copy-on-select.ts`）：鼠标松开时页面上有选中的文字（拖选、双击、三击）就写进剪贴板，不弹提示（用户刚做的就是复制）；同一段选区只复制一次；键盘选中不自动复制；输入框、文本域、可编辑区、内置终端里的选中不复制（在那里选中多半是要改写或粘贴覆盖）。写剪贴板要 `clipboard-sanitized-write` 权限，主进程只对应用自己页面的主框架放行，其余权限照旧全拒（`main/window/security.ts`）。
