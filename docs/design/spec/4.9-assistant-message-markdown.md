# 4.9 AssistantMessage 与 Markdown

- 助手消息是 omp 的 `omp.assistant` 节点（`col`）：思考块（`omp.thinking*`，`section`）和正文 `md`，由 `features/tsp/` 画（`nodes/layout.tsx` 的 `AssistantCol`）；无气泡、无头像、无名字。复制回答用 omp 放在每轮用量行里的图标（`omp.turn.copy`，右键菜单 复制 Markdown / 复制纯文本），或命令面板的“复制最后一条回答”。
- **回答操作行**（issue #9 照 ompweb，仓库所有者批准，2026-11-09）：用量行里 omp 的复制图标后面，studio 加两个一直显示（不靠悬停）的图标按钮：复制纯文本（同右键菜单那一项）、从这里分叉（新任务的对话到这条回答为止，输入框空着；任务不空闲时 `aria-disabled`）。omp 实时画的行和 studio 恢复会话时补的行都有；omp 自己的行里将来有了同样的动作，那一个 studio 不再画。语义见 `docs/architecture/session-tree.md`「回答上的分叉」。
- **没有“叙述 / 结论”之分**：一轮里的助手文字和工具卡片按 omp 发来的顺序排列，studio 不拆分、不挑结论，也没有“没有得到结果”兜底。
- 流式：`md` 节点带 `stream: true` 时按流式渲染（`nodes/text.tsx` 传给 `Markdown` 的 `streaming`）。
- 思考块折叠与否跟着节点的 `collapsed`（§4.11）。思考头照 Tern 里的 omp：斜体，折叠箭头跟在用时后面（`✳ Thinking… 2.7s ›`），不在行首。
- **每轮用量行**：omp 在每轮最后一个助手消息里发 `omp.turn.usage`（复制图标 · 时长 · token · 费用，悬停是完整明细），文字是 omp 原样的英文；复制图标后面 omp 单独发的那个 `·` 不画（紧跟图标读起来像列表断了头）。恢复会话时 omp 不重发这一行，studio 从会话文件补回（§4.14“恢复会话时补回的用量脚注；空闲回顾照 omp”）。
  - 悬停提示在 omp 的明细后面 studio 补两行（实时的行和补回的行都补；英文，过程区不汉化）：`Cache hit rate 96%`（issue #10：缓存读取 ÷ (输入 + 缓存读取 + 缓存写入)，同会话信息页；缓存读写都是 0 时没有这一行）、`Finished <本地时刻>`；可见文字不变（`turn-footer.ts` 的 `withTurnDetails`）。
  - 对齐：补回的行要求文档和会话文件轮数相等；实时的行按末尾对齐——压缩后 omp 删掉旧的几轮，文档里的轮比会话文件少，这时 token 数和 omp 的明细对上才补。
- Markdown 样式在 `markdown/markdown.css`；对话里不用大标题，表格外层可横向滚动，无斑马纹。行为规则：

| 元素 | 规则 |
|---|---|
| 任务列表 | 只读复选框 |
| 链接 | hover 才下划线，tooltip 显示完整 URL；http/https 交给主进程用系统浏览器打开。过程区回答（`md` 节点）里的文件链接（`file://` 和不带协议的路径，`#`、`?`、`//` 开头的不算）在右侧预览打开（`openHref`，同工具卡上的路径；越界、不存在由预览页说明），二进制文件在预览页给“用默认应用打开”（照 omp 18.13.1 终端版只把这两种画成链接、Tern 在文件块里打开 `file://`）；其余地方的 Markdown 没有任务目录，这类链接只显示文字 |
| 原始 HTML | **转义成文本**，不渲染（`docs/architecture/security.md`「不可信内容」） |
| 图片 | `data:` 直接显示；本地路径的图片在任务目录里就直接显示（最高半屏，点了在右侧预览），读不到的显示成图片图标 + 说明文字的链接，悬停看路径；远程图片和网络路径不加载，远程显示为链接 |
| 公式 | KaTeX（`direction-3.1.md` §2 行 9；分隔符识别在 `markdown/math.ts`，渲染在 `render.ts` 的 `renderMath`）：行内 `$…$`、`\(…\)`；块级 `$$…$$`、`\[…\]`，分隔符在行首，块级居中、太宽时横向滚动。`$` 按 pandoc 规则（开 `$` 后紧跟非空白，闭 `$` 前非空白且后面不是数字），所以 `$5 and $10` 不是公式；`\$` 是普通的 `$`。跨行的块级公式中间遇到空行就不算公式。没闭合的分隔符按普通文字显示（流式中公式还没写完时就是这样）。解析失败时用错误色显示原文（带分隔符）。`trust: false`：`\href`、`\url`、`\includegraphics` 不放行 |

- 用户文本不进 `dangerouslySetInnerHTML`；唯一例外是 KaTeX 渲染出的公式 HTML（`renderMath`，`trust: false`，公式里的文字由 KaTeX 转义）。Markdown 库要求：能拿到块边界、可关闭原始 HTML。
