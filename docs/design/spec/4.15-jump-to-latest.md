# 4.15 JumpToLatest 药丸

仅当用户脱离吸底且有新内容时出现；对话区底部居中，文案 `scroll.latest`；点击或 `End`/`Ctrl+End` 回到底部并重新吸底。

**对话线**（`ConversationLine.tsx`，仓库所有者定，2026-10-22）：会话里有 2 条以上用户消息时，对话区右缘（覆盖式滚动条左边）一列横刻度，每条用户消息一个，按发送顺序从上往下（取自 TSP 文档里的 `omp.user` 卡片，`shared/tsp/user-messages.ts`）。
- 正在读的那一条 = 顶边在视口上 1/3 以上的最后一条（吸底时是最后一条），`aria-current="location"`。刻度长短变化走 transform，不动 `width`：滚动时当前那一条一直在换，过渡 `width` 每帧都要重新排版。
- 点刻度把那条消息滚到对话区顶部。读屏 `scroll.lineItem`（第几条 + 消息开头）；没有悬停提示，悬停展开下面的大纲。
- 整列在对话区的高度里竖直居中；消息多时刻度间距压缩、可用整个对话区高度，再多就在列里滚动（不显示滚动条），溢出时从第一条排起。刻度之间的空白不接点击。列要窄：对话列贴满最小留白时，宽了会贴着用户气泡右缘。

**对话大纲**（仓库所有者定悬停展开、不加按钮，2026-11-09）：指针移到刻度上、或键盘把焦点带进刻度（只认 `:focus-visible`，鼠标点出来的焦点不撑开）时，刻度列左边展开一张大纲（`conversation-outline`，`role="group"`）：窄窗里限宽不压太多正文，高不超过对话区，内部滚动，打开时把当前行滚进视野。
- 每条用户消息一行：序号 + 消息第一行（`outlineLabel`：第一行非空文字，跳过代码围栏，去掉 Markdown 标记），正在读的那条突出 + `aria-current="location"`；点行同点刻度。
- 指针离开对话线和大纲后延迟收起（从刻度移到大纲要跨过中间的空隙）；焦点离开也收起。
- 键盘：刻度之间、大纲行之间 `↑ / ↓` 移焦点（到头不动），`Enter` 跳过去，`Esc` 收起并把焦点放回当前刻度（这个 `Esc` 不写给 omp、不停止任务）。命令面板“对话大纲”（`palette.outline`）打开它并把焦点放在当前行。上一轮 / 下一轮见 §5.1。
- 跳转（点刻度、点行、快捷键）都会让对话区离开吸底（`scroll-bus.ts` `requestLeaveBottom`）：键盘跳转没有指针按下，跳完的滚动和流式追加挤在同一帧时会被当成布局变化又贴回底部。刚跳到的那条在滚动位置不变时就是“正在读的”：短对话滚不到让它在顶上，按位置会算成最后一条。
- 只有压缩点之后的消息（omp 只画这些）。
