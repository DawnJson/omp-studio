# 4.5 Sidebar 外壳

## 顶部操作

顶部竖排三行（`direction-3.0.md` §3.1）：搜索框 / `新任务` / `打开文件夹`（`sidebar.openFolder`：选文件夹、加进项目列表，并把草稿切到它）。

- **搜索框**：`ui/TextField` sm、通宽、`role="searchbox"`、`data-testid="sidebar-search"`；空时右端常显 `Ctrl F` 后缀（`.ui-affix`），有内容时换成清除按钮（`sidebar.clearSearch`）。`Ctrl F` 聚焦并全选；有内容时 Esc 先清空，`↓` 直接进列表。聚焦样式同其他输入框（§4.23）。它直接过滤任务和会话，不是命令面板。
- `新任务` / `打开文件夹` 两行同一种样子（无边框透明底，图标 + 文字）；右边的快捷键提示 `aria-hidden`，**平时不显示，悬停或键盘聚焦这一行时才出现**，占位不变。侧栏和菜单里的快捷键提示（`.ui-affix`、`.ui-menu-hint`）统一用 UI 字体小字、不画键帽；键帽 `.ui-kbd` 只用在命令面板右列和悬停提示里。
- 草稿页时 `新任务` 带 `aria-current="page"` 和选中底色。

## 列表

操作按钮和等待条下面只有**一个列表**（仓库所有者定，2026-10-20：分开的任务块和历史会话区会让同一个文件夹出现两次）。组件 `features/sidebar/HistorySection.tsx`，数据整理在 `shared/ui/sidebar-model.ts` 的 `buildFolders` / `buildChats` / `buildArchived`。

- 内容：studio 任务 + omp 会话目录里还没挂在任务上、没归档的会话（含终端里开的），不搜索也显示；移出列表的项目（§4.3）的任务和同一目录的会话不列。
- **区块标题行**（`.sb-history-head`：`sidebar.searchHistory`"任务" + 分段）sticky 在滚动区顶部，滚动时**完全不动**。gotcha：滚动区（`.sb-list`）不能有上内边距，否则 sticky 会先跟着走一段再钉住，或上面留缝透出滚过的行。顶部三行和等待条在滚动区外。
- **分段**：`ui/Segmented` sm（`data-testid="sidebar-history-by"`），`项目 | 对话`，记在 `ShellState.historyOrder`（`folder` / `chats`，默认 `folder`；旧版存的 `time` 读回来按默认）；有归档的会话时多第三段 `归档`（issue #9），不记进外壳状态，最后一条恢复后自己回到原来的分段。分段：项目 / 对话 / 归档（2026-11-10 仓库所有者定，学 Claude Code 的项目和对话分开）。
- 选中的任务换了、而它在另一段时，切到它所在的那一段（在"项目"里点 `新任务` 发出第一条，任务在默认文件夹里，侧栏切到"对话"）；只在选中项变化时切一次。

**项目**：

- 文件夹 = studio 项目 ∪ 会话 cwd，按规范化路径合并（斜杠、大小写、尾斜杠归一），**不含默认文件夹**（`AppInfo.chatsDir`，在"对话"里）；文件夹头见 §4.3。
- 文件夹里任务行（§4.2）和会话行混排，按最近活动从新到旧（任务取 `lastActivityAt`，会话取修改时间）。
- **文件夹的顺序由用户定**（2026-11-10 仓库所有者定，学 Claude Code：列表不在眼前自己跳）：拖文件夹头换位置，或焦点在头部时 `Alt+↑` / `Alt+↓`（§4.3）；任务跑完、发消息都不挪文件夹。新出现的文件夹（新开的项目、终端里新目录的会话）排在最前，一出现就记进顺序，之后不再自己动；第一次用时按当时的最近活动定下初始顺序。顺序记在 `ShellState.folderOrder`（文件夹 key 列表，`sidebar-model.ts` 的 `adoptNewFolders` / `moveFolder`）；移出列表的项目也留在里面，再打开回到原位。搜索时没有匹配行的文件夹不显示。
- 展开：用户点过的优先；没点过时，有选中、正在跑或等你确认的任务的文件夹默认展开。**自动展开过的文件夹不会自己收起**，只有用户点了才折叠（所有者报告"任务跑完侧栏的会话自动折叠"后定，2026-10-25；`Sidebar.tsx` 的 `autoOpened`）。
- 展开后先显示少量行（选中、运行中、等你确认的任务不会被藏进"显示更多"），`sidebar.showMore` 每次加一批；展开状态只在本次会话里。

**对话**：默认文件夹（不属于任何项目，`新任务` / `Ctrl N` 开的）里的任务和会话平铺一列，按最近活动从新到旧，同样分批"显示更多"。

**归档**：归档的会话平铺一列，同样的会话行，按修改时间排序，可搜索；点开 = 恢复成原来的任务（同一 id）；右键菜单只有 `task.delete`（`session-menu-delete`，确认和删除同 §4.2；issue #10）。

**分叉缩进**（issue #9）：

- 会话头 `parentSession` 指向的会话（`SessionSummary.parentId`）在同一个列表里时，分叉的行排在原会话后面、整行右移一层（`.sb-row[data-depth]`，有层数上限），兄弟之间新的在前；原会话被搜索滤掉、在别的文件夹或已归档时分叉照常顶层。
- 分叉出来的任务沿用原标题，不加"（分叉）"后缀（缩进已经说明了关系）。分叉行标题前一个分叉图标，缩进区每层一条竖向引导线，连着的行接成一条线。
- **收起分叉**（仿 ompweb）：下面有分叉的行在状态槽后面多一个箭头（`data-testid="sidebar-fork-toggle"`），点它收起 / 展开整棵分叉，默认全部展开。收起后不加可见文字，藏了几行只写在悬停提示和 `aria-label`（`sidebar.expandForks` / `sidebar.collapseForks`）。选中 / 在跑 / 等你确认的行即使在收起的分叉里也照常显示，连同通往它的上级行；搜索时不管收起；"显示更多"只数看得见的行。
- 收起状态按行（`SidebarItem.key`）存在 `Sidebar.tsx` 组件状态里，和文件夹展开状态一样**只在内存**，重开应用回到全部展开；规则是 `sidebar-model.ts` 的纯函数 `foldForks` / `visibleItems`。

**会话行**（`sidebar-session`）：状态槽（只画失败 / 中断，§4.2）+ 标题（无标题取首条消息）+ 修改时间，**和任务行同高、同一套 `.sb-row` 样式**；悬停提示标题和 cwd；点开 = `resumeSession` 恢复成任务（项目不在列表里时自动加入）；右键菜单 `task.archive`（`archiveSession`：建一条已归档的任务记录，不起 omp、不动会话文件）—分隔线—`task.delete`。任务列表变化时重取，挂上任务的会话随即以任务行出现。

**标题清理**：任务和会话标题显示前去掉私用区图标字形（`shared/ui/clean-title.ts` 的 `stripIconGlyphs`，和主进程 TSP 标题同一个集合）：omp 的会话标题带这些字形，系统字体里没有，会显示成方框。

**搜索**同时过滤任务和会话（按清理后的标题，不区分大小写），两种排列一样；按文件夹时有匹配的文件夹全部展开，没有匹配的不显示。

键盘：整个列表一个 Tab 停靠点，`↑↓` 移动。侧栏自己没有头（标志和切换侧栏在顶栏）；列表区自绘覆盖式滚动条。

## 底部

- 只有一个 `设置` 文本按钮，是开关（`aria-pressed`）：在设置页时再点回到对话视图，同设置页里的 Esc。
- 没有语言、主题按钮（`direction-3.2.md` §7 第 5 条）：它们只在设置 → 通用 → 外观（§4.19）。命令面板只走 `Ctrl K`。底部不放键帽、不放小字。
- **新版本标签**（`.sb-update`，`data-testid="sidebar-update"`）：更新下载完成（`UpdateState.phase === "downloaded"`）后出现在 `设置` 右边，强调色圆点 + `sidebar.update`，不描边、不填色，悬停提示 `sidebar.updateTip`。不弹窗、不弹 toast，只淡入出现。放不下时它的文字省略、`设置` 的文字让出（900 宽窗口中英文都不越界）。点它走下面的"安装规则"。

## 安装规则

侧栏标签、设置 → 关于、关于对话框三个 `重启并安装` 入口共用 `features/settings/use-install-update.tsx`：

- 有任务在进行（`running` 或 `needs_you`）就先弹 `ConfirmDialog`（`settings.about.installConfirmTitle` / `installConfirmBody`，默认焦点在 `稍后`）；不用 danger 样式：任务能从历史会话继续，不是不可逆操作。没有任务在进行就直接安装。
- 安装失败弹 error toast（`settings.about.installFailed`，全仓统一用 toast）。
- 退出软件时 electron-updater 自动安装已下载的更新，不走确认。
