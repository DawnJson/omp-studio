# 4.1 StatusDot（状态槽）

状态以主进程为准，渲染层只收 `taskState` 事件；判定在 `shared/ui/sidebar-model.ts` 的 `dotKind`，图形在 `StatusDot.tsx`。

| 状态 | 视觉 | aria-label |
|---|---|---|
| `running` / `starting` | 转动的圆弧（减少动效或 `--play-state` 暂停时静止） | `status.running` |
| `needs_you` | 实心圆 + `!`，静止 | `status.waiting` |
| `error` | 实心圆 + `×` | `status.error` |
| 正常结束、还没看过（主进程 `TaskState.unread`：结束时不在前台，切进去清掉） | `--st-done` 绿色实心小圆点 | `status.unread` |
| 看过的正常结束 / 从没跑过 / `aborted` | 不画，槽位保留让标题对齐；`aborted` 在尾部显示 `task.stopped` | — |

看过的正常结束**不画**（仓库所有者定，2026-11-09：侧栏去掉已完成任务的勾）；后台跑完、还没点开看过的画绿点、标题变亮（`.sb-row[data-unread]`，同选中、等待），点开后两样都消失（仓库所有者定，2026-11-11；颜色是绿色）。文件夹收起时头部也带同样的点（§4.3）。`error` 保持到用户在该任务开始新一轮。
