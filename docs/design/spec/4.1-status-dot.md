# 4.1 StatusDot（状态槽）

状态以主进程为准，渲染层只收 `taskState` 事件；判定在 `shared/ui/sidebar-model.ts` 的 `dotKind`，图形在 `StatusDot.tsx`。

| 状态 | 视觉 | aria-label |
|---|---|---|
| `running` / `starting` | 转动的圆弧（减少动效或 `--play-state` 暂停时静止） | `status.running` |
| `needs_you` | 实心圆 + `!`，静止 | `status.waiting` |
| `error` | 实心圆 + `×` | `status.error` |
| `idle` 正常结束 / 从没跑过 / `aborted` | 不画，槽位保留让标题对齐；`aborted` 在尾部显示 `task.stopped` | — |

正常结束（`lastTurn.status === "completed"`）**不画**（仓库所有者定，2026-11-09：侧栏去掉已完成任务的勾）；有没有新结果靠标题颜色区分（§4.2）。`error` 保持到用户在该任务开始新一轮。
