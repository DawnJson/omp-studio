# 4.10 CodeBlock

外观和过程区的工具卡片一致（同底、不描边），否则和工具卡并排时像两套东西；样式在 `markdown/markdown.css`。头部左边语言名（无语言显示 `text`），右边复制图标按钮（hover、聚焦代码块或 Tab 到它时显示，复制后形变成对勾再变回（§2.6 图标形变），`aria-live` 播报 `common.copied`）。长行折行，不横向滚动（工具卡输出、门里的预览、设置里的 JSON 编辑框同样折行）。**全文显示，不折叠**：omp 的 `md` 节点不限行数。流式中以最终样式创建，围栏闭合后**只改颜色**加高亮；闭合前不高亮。` ```diff ` 只给整行文字着色，不加背景条。

**`svg` 代码块画成图**（照 omp 18.12.6 在 TUI 里的做法）：只在代码块闭合后画（流式中途还是源码）。omp 约定的颜色变量（`var(--fg)`、`--accent`、`--c1`…`--c6` 等，带默认值的写法也认）和 `currentColor` 在画之前替换成当前主题的实际颜色（`markdown/svg-figure.ts` 的 `FIGURE_TOKENS`），补上 `xmlns`，转成 `data:image/svg+xml` 交给 `<img>`——`<img>` 里的 SVG 不执行脚本、不加载外部资源，CSP 本来就允许 `img-src data:`，不用 `dangerouslySetInnerHTML`。切深浅主题时重画。图左对齐，1 个 viewBox 单位 ≈ 1px，宽了按比例缩到列宽；不铺底色（omp 约定画布就是读者的主题）。头部复制按钮左边多一个 `<>` 按钮（`codeblock-source`，`aria-pressed`）在图和源码之间切换；`<img>` 加载失败时退回源码，上面一行 `code.figureFailed`。

**`mermaid` 代码块画成图**（仓库所有者批准新增依赖 `beautiful-mermaid`，2026-10-27）：omp 的 `tui.renderMermaid`（默认开）让模型用 mermaid 画图，终端版只认 flowchart、state、sequence、class、ER、xychart 六种；`beautiful-mermaid` 同样这六种，画成 SVG 后走上面 svg 图同一条路。只在围栏闭合后画；布局在 worker 里算（`markdown/mermaid-worker.ts`），画好之前显示高亮的源码。颜色只由代码块底色和正文色按比例混出来，不另取 token；不铺背景，去掉库自带的外链字体；切深浅主题只换颜色、不重新布局。`<>` 按钮同 svg 图；写错或不支持的图种（饼图、甘特图等）显示源码 + `code.figureFailed`。

**引用到输入框**（仓库所有者批准，2026-11-09）：任务对话区里（`TspView` 提供 `CodeQuoteCtx`，`markdown/code-quote.ts`）闭合的代码块头部在复制按钮后面多一个引号图标按钮（`codeblock-quote`，`code.quote`）：把这段代码作为带语言的围栏代码块（代码里有 ```` ``` ```` 时围栏加长）接在当前任务草稿末尾（`appendToDraft`），焦点给输入框。不在任务对话区的代码块（文件预览、设置页更新说明、子代理面板、旁路提问）没有这个按钮。

**在侧栏预览**（仓库所有者批准，2026-11-10）：任务对话区里（`TspView` 提供 `CodePreviewCtx`，`markdown/code-preview.ts`）闭合的 `html` / `htm` / `svg` / `mermaid` / `markdown` / `md` 代码块（不分大小写），引用按钮后面再多一个图标按钮（`codeblock-preview`，`code.preview`）：打开这个任务的文件面板、停在预览页显示这段代码（§4.27“代码片段”）。流式中途、别的语言、以及不在任务对话区里的代码块（没有面板可开）没有这个按钮。
