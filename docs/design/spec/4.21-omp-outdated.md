# 4.21 omp 版本过旧

不全屏，没有主区顶部横幅。低于最低版本时：设置 → 关于的 omp 卡片顶部一条错误 `Notice` `omp.outdated`（`OmpSection.tsx`，挂在 `AboutSection.tsx` 里），同时**禁用发送**（输入框区显示 `composer.versionTooOld`，`Composer.tsx`）。升级也在这张卡片里：PATH 上用户自装的 omp 有 `omp.upgrade` 行（执行 `omp update`，显示输出尾部）；受管者管理（Tern 等）没有升级按钮，行说明写 `omp.updateByManager`。运行中有任务时升级没有额外提示。有新版但不强制：只在这张卡片里显示 `omp.newVersion`，不弹窗不横幅。
