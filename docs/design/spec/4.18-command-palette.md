# 4.18 CommandPalette（`Ctrl K`）

居中浮层（`features/palette/`，尺寸、动效、颜色在 `palette.css`），背后遮罩，点击 / Esc 关闭。输入行 `flex: none`：列表比面板高时也不被压扁。输入行右边一个 `Esc` 键帽，没有悬停提示，也没有底部提示行。结果行 `[图标][标题][右侧：项目名/快捷键键帽]`，当前行左边竖条常驻、只切透明度。斜杠命令行不画图标（标题本身以 `/` 开头），图标位留空，标题仍和其它行对齐；`palette.noResults` 那行和分组标题同一种样子；**无结果的分组不渲染**。键帽一律 `<kbd class="ui-kbd">`。

- 空查询：`palette.recent`（最近几个任务）→ `palette.commands`。有输入：任务（标题+项目名模糊匹配）→ `palette.sessions`（含终端历史会话，`>_` 标）→ 命令 → 斜杠命令（仅当前任务有进程时，`get_available_commands`）；输入以 `/` 开头时只显示斜杠命令。匹配字符高亮。
- 无结果：`palette.noResults` + 一行 `palette.askNew`（把查询当成新任务的 prompt）。
- 命令清单以 `palette-commands.ts` 的 `buildCommands` 为准（“当前任务”类只在有任务时列，目标类按目标状态列，重试上一轮只在空闲时列）。要点：选择主题打开设置 → 通用（主题画廊在页首），不轮换；对话大纲（`palette.outline`）回到对话页、展开大纲并把焦点放在正在读的那一行（§4.15）；关于与反馈（id `about`）经 `emitStudioCommand("about")` 由 `app/App.tsx` 打开 `AboutDialog`（§3.1）；集成类（插件、MCP、SSH、工具、记忆、omp 更新）跳到设置页对应分节；会话信息类见 §4.31。**每个快捷键动作必须在此有一条**。每条命令按 id 配图标（`palette/command-icons.ts` 的 `commandIcon`），没登记的回退到 `CommandIcon`。
- 键盘：`↑↓` 移动，`Enter` 执行，`Ctrl+Enter` 在新任务中执行，`Tab` 无动作（焦点陷阱）。打开前记住 `document.activeElement`，关闭后还原（那个元素已被移除时不抢焦点）。
