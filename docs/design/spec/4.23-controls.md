# 4.23 通用控件（3.2 起，`direction-3.2.md` §3）

全部在 `src/renderer/src/ui/`：React 组件 `controls.tsx`（Button、IconButton、Switch、Checkbox、Segmented、Tabs、Badge、Notice、TextField、NumberField、Textarea、FormField、SectionHead、Row、ListRow、Disclosure）、`Select.tsx`、`Menu.tsx`（`Menu` / `MenuList`）、`Popover.tsx`、`Dialog.tsx`（`Dialog` / `ConfirmDialog`）、`InfoTip.tsx`；样式只在 `controls.css`，类名前缀 `ui-`，只用 token；ask 门的单选圈直接用 `.ui-radio` 类。各功能目录**不自己写**按钮、开关、分段、下拉、菜单、对话框外壳的样式。样张 `docs/design/3.2/components.html`（浏览器直接打开，`?theme=dark` 看深色）。

**尺寸只有两档**：md `--control-h-md`（表单、对话框、设置页）、sm `--control-h-sm`（工具条、面板和分组标题、列表行、浮层）。圆角：按钮、输入框、分段外框 `--radius-md`；分段内块、勾选框 `--radius-sm`；胶囊形只给输入框工具条的 Chip 和 Toast。**一个视图最多一个主按钮**；链接只出现在句子里，不当独立按钮。**互斥取值**：≤4 个短选项用 Segmented，更多用 Select，由选项个数决定，不由语言或宽度决定（例外：模型选择器的思考强度是有序的档位，仍是一排分段，`direction-3.2.md` §5）；**切视图**用 Tabs。

**通则**（仓库所有者同意，2026-10-22）：

| 规则 | 做法 | 范围 |
|---|---|---|
| 输入框聚焦不画外描边 | 边框隐去，换成两层阴影 `0 0 0 1px --accent` + `0 0 0 4px --accent-soft`（错误态 `--st-error` / `--st-error-soft`），同时 `outline: 2px solid transparent`（Windows 高对比度模式清掉阴影时靠它显示焦点） | Field、Select、Textarea；按钮、菜单项、开关的键盘焦点仍是全局 `:focus-visible` 的 2px 外描边 |
| 句子里的图标下移 0.125em | `vertical-align: -0.125em`（现在只有 ⓘ `.ui-info`）；设置行标签是普通文字块，ⓘ 跟在最后一个字后面，英文标签折两行时不漂到列尾。ⓘ 是 inline-block，前面总有折行机会（U+2060 词连接符在 Chromium 里也拦不住），所以 ⓘ 前面那个元素末尾留出 ⓘ 的位置（`padding-inline-end`），ⓘ 用负 `margin-left` 退回去：排版时 ⓘ 不占宽，放不下时最后一个字带着这块位置一起折行（`ui/controls.css`；e2e `expectInfoTipsOnLabelLine`） | 只给夹在文字里的图标；flex 容器里的图标（按钮、菜单项、胶囊）不加 |
| 多行文字 `text-wrap: pretty`，短标题 `balance` | `pretty`：帮助文字、菜单项第二行、浮层正文、对话框说明、分组说明、提示条；`balance`：浮层标题、对话框标题 | 对话流正文属于过程区，不动 |
| 几像素大的 SVG 图形取整 | 刻度条、细线的宽、间距、高度都取整数像素（高度 `Math.round`），`viewBox` 和 `width/height` 一比一；画完放大截图逐像素看。小数坐标在 1x 屏上被抗锯齿成两列半透明像素，暗色主题里低档的灰条几乎看不见（`ModelChip.tsx` 的 `EffortBars`） | `ui/` 和各功能里手画的小 SVG |

| 控件 | 规格 |
|---|---|
| Button `.ui-btn` | `data-variant`：`primary`（`--primary` 底、`--text-on-primary`）、默认次要（透明底 + 1px `--border-strong`）、`quiet`（无框 `--text-2`，"稍后""显示全部"）、`danger`（红字 + 红框）、`danger-solid`（`--st-error` 底、`--text-on-danger`，只给破坏性确认框的确认键）。`data-size="sm"`（`--control-h-sm`，`--fs-sm`；sm 的 TextField、Segmented 同样是 `--fs-sm`）。加载：文字透明、**宽度不变**、显示加载环，同时禁用。禁用：`--text-disabled` + `--border`。快捷键提示 `.ui-hint`：按钮里尾随的等宽淡色小字，不画键帽框 |
| IconButton `.ui-icon-btn` | 方形（sm / md 两档），无框，`--text-2`，悬停 `--bg-hover`，按下 / 展开 `--bg-active`；必须有悬停提示（`label`，可另给 `tip` 带快捷键）。"刷新"永远是 ↻ 图标按钮 |
| Field `.ui-field`（TextField / NumberField） | 文本、数字、搜索、下拉触发器共用：`--bg-raised`，1px `--border-strong`，`--radius-md`；错误时 `--st-error` 边，错误文字在框下一行（`.ui-help[data-tone=error]`）。数字框定宽、右对齐、`tabular-nums`，单位写在框内（`.ui-affix`）。前后可放图标（搜索、清空） |
| Select `.ui-select` | Field + 右侧 chevron；**不给 `width` 时按最长的选项（和占位文字）定宽**（`data-fit`：当前值和每个选项的文字叠在同一格里撑开宽度，看不见；短选项的下拉不该是一个大框，仓库所有者定，2026-10-23），短内容的下拉不写死宽度；选模型这类长内容给 `width="100%"` 撑满所在列。展开的列表是选择菜单（portal 到 body、`fixed` 定位，下方放不下向上展开；展开那一侧到窗口边（留一点边距）的高度是整个弹层（搜索框 + 列表）的上限，窗口矮时列表在里面滚、不出窗（e2e `custom-models.e2e.ts`「窗口很矮时」）；窗口尺寸变化时关闭；**滚动时只有触发器真的被滚走了才关**：内容加载时的滚动锚定这类不挪动触发器的 scroll 事件不算，否则刚进设置页就点下拉，列表会被页面自己的 scroll 事件立刻关掉；层级 `--z-menu`，在对话框遮罩之上，对话框里的下拉也能选）。键盘：焦点留在触发器（combobox + `aria-activedescendant`），`↑↓` / `Home` / `End` 移动，`Enter` / 空格选择，`Esc` 关闭，首字母跳转。给了 `search` 时列表上方一个搜索框（`{testId}-search`，打开就聚焦，菜单定宽，过滤时不跳宽；名称或值包含即可，空格和 `Home` / `End` 留给输入；没有匹配写 `common.noMatches`）。选项带 `group` 时按组折叠（组头 `{testId}-group`，`data-group`，chevron 转 90° + 计数，`ui/Reveal` 展开收起；默认只展开当前值所在的组，有搜索词时匹配的组都展开，收起的组里的项不能移动到）。设置里所有选模型的下拉（模型页的角色表、`modelRoles` / `retry.fallbackChains` 编辑器）都带搜索、按 provider 分组，组按 provider 名排（同模型选择对话框），组内该角色自己的类别在前 |
| FormField `.ui-form-field` | 竖排字段：标签在上、控件、帮助 / 错误在下。**列写 `minmax(0, 1fr)`**：隐式的 auto 列会被不换行的内容撑宽，对话框里并排字段（如 SSH 的用户名 + 端口）、整张表单（`.ig-form`、`.cp-form`、`.pv-flow`）会跟着出对话框的右边界。对话框 / 表单里的 `display: grid` 容器一律显式写列：单列 `minmax(0, 1fr)`，并排 `minmax(0, 1fr) <固定宽>`；检查方法见 `test/e2e/settings-functional.e2e.ts` SSH 段的右边界断言 |
| Textarea `.ui-textarea` | 同 Field 的框，`resize: vertical`；`mono` 变体用 `--font-mono` |
| Switch `.ui-switch` | 关 `--border-strong`（两套主题都看得见），开 `--accent`；被系统强制打开的：禁用的开 + 旁边一个徽标说明原因 |
| Checkbox / Radio `.ui-check` `.ui-radio` | `--border-strong` 描边，选中 `--accent` 底；ask 门单选题用单选圈、多选题用勾选框，标记后面是序号（`tspi-item-n`，`--font-mono` `--fs-xs` `--text-3`，前 9 项，按数字选它） |
| Segmented `.ui-seg` | 设一个值：外框 `--bg-active`，选中块 `--control-on` + `--shadow-1`；`role="radiogroup"`，方向键移动并选中 |
| Tabs `.ui-tabs` | 切一个视图：文字标签 + 当前项 2px `--text` 下划线，可带计数；`role="tablist"`，方向键移动并切换 |
| Badge `.ui-badge` | `--radius-sm`、`--fs-2xs`；neutral / accent / success / warning / error，可带圆点。状态、范围、来源、"推荐""默认"都用它，不用整句彩色文字 |
| Menu `.ui-menu` | `--bg-overlay` + `--shadow-2` + `--radius-lg`，`padding: --space-1`，项高 `--row-menu`。第一列：动作菜单放图标，选择菜单放 ✓（**当前项只靠 ✓**，灰底只表示悬停 / 键盘焦点）；破坏性项红字、放最后、前面一条分隔线；不可用项灰字，原因写在第二行小字；小节标题 `--fs-2xs` `--text-3`；限宽。`Menu` 按锚点 `fixed` 弹出，贴边时翻到锚点另一侧；打开时焦点进第一项，`↑↓` 移动，`Esc` / 点外面关闭，焦点回到打开它的元素。`MenuList` 是嵌在 Popover 里的同一种菜单。文本框的右键菜单（`app/EditMenu.tsx`）也是它：撤销 / 剪切 / 复制 / 粘贴 / 全选，按有没有选区、能不能写列出（密码框不给剪切 / 复制），命令经 `editField` 交给主进程对聚焦的输入框执行（渲染进程不读剪贴板，粘贴照常走 paste 事件）；自己画右键菜单的地方先 `preventDefault`，它就不弹。过程区节点的右键菜单（omp 的 `actions.menu`、回答复制图标的 复制 Markdown / 复制纯文本；`features/tsp/TspHosts.tsx`，`tsp-menu`，读屏名 `tsp.nodeMenu`）也是它，贴边时同样翻边（e2e `tsp.e2e.ts`「对话里的右键菜单贴着窗口右下角打开时」） |
| Popover `.ui-popover` | 输入框胶囊上方弹出的浮层：`--bg-overlay`、`--shadow-2`、`--radius-lg`；确认类内容定宽，标题 `--fs-sm` 粗、正文 `--text-2`、按钮 sm 右对齐。**同一时刻只开一个**：新开的会关掉已开的（`/todo` 再 `/jobs` 不叠放）；`Esc` 只关最上面（最后打开）的一个并被消耗（不会再当作"停止任务"），焦点在输入框、胶囊或浮层里都管，焦点在 `aria-modal` 对话框或 TSP 过程区里不管；从输入框用斜杠命令打开的，关闭后焦点留在输入框。**不出可见区域**（`fitInside`）：横向挪回最近的裁剪祖先（一般是主区面板）里，最高 `min(60vh, 到边缘的高度)`，向上弹出的量到顶边，向下弹出的（`bottom: auto`，如自定义提供商的拉取浮层）量到底边（e2e `custom-models.e2e.ts`「窗口很矮时」） |
| Dialog `.ui-dialog` | **唯一外壳**：sm / md / lg / xl（`--dialog-w-*`；xl 给要横向空间的用量、模型选择），`--radius-lg`、`--shadow-modal`，居中、遮罩 `--bg-scrim`；标题 `--fs-lg` + 可选一句说明，右上 ×（纯告知、页脚只有一个“关闭”的对话框传 `hideClose` 不画 ×，免得两个关闭入口，如合并冲突、清理报告；选择器类对话框可以用 `head` 换掉标题行：顶上是搜索框，标题只作读屏名、没有 ×，如模型选择）；正文竖排字段（`FormField`：标签在上，帮助 / 错误在下）；页脚按钮右对齐、取消在前确认在后，附带选项放页脚左侧。`Esc` 关闭并被消耗，`Tab` 在对话框内循环，打开时焦点进 `[data-autofocus]`，没有就进对话框本身（不进 ×：一打开焦点环套在 × 上，视觉重心落在关闭按钮），关闭时焦点回到打开前的元素。焦点掉到 body（按下的按钮转成 loading 被禁用、获得焦点的元素被卸载）时，`Esc` 照样关最上面的对话框、`Tab` 把焦点拉回对话框。自己管开关的对话框（打开即挂载，放完退出动画才通知父级）由父级用 `useDialogSlot`（`ui/presence.ts`）记开着的是哪一次：退出动画没放完又点打开，立刻开一个新的，旧实例迟到的通知不会把它关掉。确认框（`ConfirmDialog`）是 sm 宽的同一外壳，破坏性确认用 `danger-solid`，打开时焦点在**取消**。**不叠对话框**；**切换选项时外框大小不变**（分段、下拉、开关、页签换内容时对话框不跟着变大变小，仓库所有者定，2026-10-24）：字段组互换的用 `ui/Reserve` 叠在一格里占最大的那份（MCP 表单的 stdio / HTTP、分享对话框勾 gist 换的警告），带 `tabs` 的 Dialog 和传 `lockHeight` 的列表类对话框（会话树、连接提供商）高度只长不缩；结果到达、增删列表项这类内容变化可以改变大小 |
| SectionHead / Row / ListRow | 分组标题 `.ui-section-head`：`--fs-sm` 粗 + 计数，右侧图标按钮或一个 sm 按钮，可带一行说明。设置行 `.ui-row`：标签列定宽，控件紧跟标签列，改过的值左侧 2px `--accent` 竖线、控件后面一个"恢复默认"图标按钮（悬停提示写出默认值）。列表行 `.ui-list-row`：图标（类别图标，provider 是 logo）、名称，名称下面一行徽标在前 + 元信息（单行省略）、动作；名称和元信息被省略号截断时悬停看全文，放得下时不出提示（`data-tip-overflow`，仓库所有者定，2026-10-30）；删除 / 移除只有一个时是 sm 按钮，两个以上收进 ⋯ 菜单。外面包 `.ui-cards` 时排成卡片网格（`auto-fill` 等宽列，`--bg-raised` 底、1px `--border`、`--radius-lg`；列宽和内边距见 `controls.css`）：两行（仓库所有者定，2026-10-29；2026-10-30 加大列宽和内边距，名称和变量名不再大多被截断）——左侧方图标块跨两行（1px `--border-subtle` 描边、不填底），第一行名称（`--fs-base` `--fw-medium`）、动作（最多一个可见的 sm 文字按钮 + ⋯ / 开关），第二行徽标 + 元信息（从名称下面开始，可以伸到动作下面）；骨架 `Skeleton variant="card"` 同高 |
| Notice `.ui-notice` | 内联提示条：左 2px 等级色 + 同色 soft 底，`--radius-md`；info（`--accent`）/ warning（`--st-waiting`）/ error（`--st-error`）；一句人话 + 最多一个动作 |
| Chip `.ui-chip` | 输入框工具条专用：胶囊，**无底色**，悬停 / 打开时 `--bg-hover`；审批胶囊写出模式名，全自动用 `--st-waiting-text` |
| Disclosure `.ui-disclosure` | 展开 / 收起一律 chevron 转 90°，内容用 `ui/Reveal.tsx` 包；不用原生 `<details>` |

**样式约定**：

- 在功能样式里改 `ui-*` 共享控件（`ui-icon-btn`、`ui-btn`）的尺寸，选择器要比单个类更具体（带上父级），不靠样式文件的加载顺序（`controls.css` 后加载，同优先级时它赢）。改完没变化时，先在探针里打出目标元素到容器的类名链，对着真实 DOM 改选择器。
- 功能样式里的类名带本功能前缀，不用别的模块的前缀（`md-`、`ui-`、`tsp-`）：全局 CSS 没有作用域，同名规则会套到别的模块上（`scripts/check.ts` 的 `css-duplicate-class` 查两个功能目录定义同一个类）。
- 删组件或删样式文件 / 规则前，逐个 grep 里面的类名在 `.tsx` 里还有没有人用：入口组件删掉后样式文件不再被 import，别的组件里的类名照样在、只是没有样式，类型检查和单测都发现不了（0.3.26 的 `conversation.css`、`.gate-btn`）。删 `tokens.css` 里的 token 同理，要连 TS 字符串里的 `"--名字"` 一起搜（`css-undeclared-var` 查引用了没声明的变量）。
- 用 `usePresence` 的弹层（`ui/Menu` 等），挂载时做的事（聚焦第一项、量位置）要按"这次打开"的依赖重跑（`Menu.tsx` 依赖 `anchor`），不能只写 `[]`：退出动画还没放完时又打开，复用的是同一个实例，`[]` 的 effect 不再执行，菜单出来了焦点却还在原处。打开时读数据、记搜索词的对话框本体（模型选择、用量、命令面板）改用 `useOpenKey`（`ui/presence.ts`）当 key，每次打开挂一份新的：否则关掉后很快再打开，模型选择的角色表还是上一次的，刚指定的角色徽标不出来。
