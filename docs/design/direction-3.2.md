### 2.4 各处的排版问题

**外壳**：任务行 32 高的白卡片和历史会话行约 22 高的纯文字混在一个列表里；语言 / 主题菜单的当前项只有灰底，和悬停分不出；产品名有 `omp studio`（标志）和 `omp-studio`（关于、安装卡片）两种；英文侧栏搜索框占位文字被截成 "Search tasks and ses..."；安装卡片按钮左对齐、关于对话框两个等宽按钮居中，和 spec 的"按钮右对齐"不一致。

**输入框与浮层**：工具条一行里胶囊有灰底胶囊（模型）、圆形实底（审批，只有图标、模式名只在悬停提示里）、裸文字（路径）、裸图标（会话开关）四种底；右栏打开时模型名被挤成 "DeepSeek V4 Fla…"；模型选择器页脚堆了四行（详情、思考强度、Prewalk + 三个原生按钮、预设胶囊 + "把当前设置存为预设…"）再加"添加提供商…"；上下文浮层在没有回复时左半边空着；用量对话框固定 620 高，没有额度账号时底部空约 230px。

**门和 omp 弹层**：ask / 审批门没有外框，看起来像对话正文；多选题未选的行没有勾选框，单选多选分不出；"Recommended" 标被挤到行尾单独一行；按钮里的 `⌥` `⌃` 是 mac 符号（`features/tsp/fmt.ts` 的 `KEYCAPS`）；会话树面板没有标题样式也没有 ×；作业：studio 的"后台任务"浮层和 omp 的 "Background jobs" overlay 两套，overlay 左边约 230px 空列、没有关闭按钮、作业结束后还盖在对话上；目标条的状态"进行中"是紫色字，像链接，挨着"暂停 / 放弃"两个文字按钮；旁路提问面板自带一个输入框 + "提问"按钮，叠在主输入框上方，一屏两个输入框，话题标签又是一种紫底胶囊。

**右栏面板**：文件面板的"文件 / 预览"和预览页里的"预览 / 源码"都叫"预览"；"+ 添加文件夹…"是独有的虚线按钮；子代理面板的小节标题（任务 / 最终输出 / 对话记录）是 12px 灰字，比里面 Markdown 的标题还小；会话信息一个对话框里两种标签列宽；请求记录表格每行约 52 高，大半是空白。

**git / 评审**：git 菜单没有图标和分隔线，"丢弃 worktree"和普通项一样；评审工具条有"退出评审"（描边）、两组分段、"折行"（按下态）、"刷新"、"发给 agent 修改"（主按钮）五种按钮样式；评论的"编辑 / 删除"是裸文字；评审提交框输入框 40 高、提交按钮通栏灰色。

**设置**（用户点名的重点）：

- 版面：应用侧栏（240，会话列表在设置里没有用）+ 设置导航（约 190）+ 内容，内容从 x≈465 开始，1200 宽的窗口 38% 是导航。
- 高级：66 个前缀小组全部折叠，每个 48 高，默认 3516px（6 屏折叠标题）；全展开 26791px（41 屏）。433 行里 161 个开关、121 个数字框、45 个文本框、20 个下拉、35 个裸 JSON 文本框；key 在 208 宽的标签列里被截（`providers.maxInFlightReq…`），每行重复前缀；枚举值中英混排（"关闭 / suggest / 开启"）。
- 行：开关 / 下拉行 44 高，输入 / 分段行 49 高（输入框 40、下拉和分段 32），控件左缘差 4px；数字框 220×40 装 "2"、"-1"，单位写在标签里"（毫秒）"，`-1` 原样显示；英文标签折两行时 ⓘ 漂到标签列最右，和文字脱开。
- 同一设置在中文是分段、英文是下拉（按宽度回退）。
- 每节结构都不一样：工具页有开关只出现在部分格子里、"可用，当前没启用"配一个开着的开关、孤零零的"刷新"链接；集成页一页两个黑色主按钮；插件页"刷新"是描边按钮、"范围"不在网格里；记忆的"查看"分段不对齐、"清空"红框；关于页标签和按钮同名。
- 表单（自定义提供商、MCP、SSH）：标签列 112，和设置行的 208 不同，一页三条左边线；输入框 40 高；"取消"是紫色链接；原生勾选框；表单在列表里展开时页面的"添加"按钮被禁用。
- 提供商：一行一句"通过环境变量或配置使用"绿色字，每行重复；同一类动作有紫色链接（"设置 API key"）和描边按钮（"添加 API key"、"登录"）两种；"显示其余 80 个提供商"展开成 87 行（5947px）；自定义提供商的"删除"是紫色链接；删除确认用黑色主按钮。
- 900 宽：设置导航折成两行药丸，应用侧栏不让位。

## 3. 通用控件（替换 spec §4.23）

样张 `3.2/components.html`，样式 `3.2/controls.css`（类名前缀 `ui-`，现有代码里没有占用）。

**尺寸只有两档**：md 32（表单、对话框、设置页）、sm 28（工具条、面板和分组标题、列表行、浮层）。输入框不再用 40；`--control-h-lg` 迁完后删掉。圆角：按钮、输入框、分段外框 `--radius-md`；分段内块、勾选框 `--radius-sm`；胶囊形只给输入框工具条的 Chip 和 Toast。

| 控件 | 规格 | 取代 |
|---|---|---|
| Button `.ui-btn` | `data-variant`：`primary`（`--primary` 底，一个视图最多一个）、默认次要（透明底 + 1px `--border-strong`）、`quiet`（无框 `--text-2`，给"稍后""显示全部"）、`danger`（红字 + 45% 红框）、`danger-solid`（红底，只给破坏性确认框的确认键）。`data-size="sm"`。加载：文字透明、宽度不变、14px 环。禁用：`--text-disabled` + `--border`。快捷键提示 `.ui-hint`：按钮里尾随的等宽淡色小字，不画键帽框 | 17 个按钮家族、`.gate-btn` |
| IconButton `.ui-icon-btn` | 28 方（`md` 32），无框，`--text-2`，悬停 `--bg-hover`；按下 / 展开 `--bg-active`。必须有悬停提示。"刷新"永远是 ↻ 图标按钮 | `icon-button`、`sb-icon-btn`、`topbar-tool`、各处"刷新"文字 |
| Link `.ui-link` | 只出现在句子里，不当独立按钮 | "设置 API key""删除""取消"这类紫色链接按钮 |
| Field `.ui-field` | 文本 / 数字 / 搜索 / 下拉触发器共用：32 高，`--bg-raised`，1px `--border-strong`；聚焦见下面"通则"；错误 `--st-error` 边，错误文字在框下一行 `.ui-help[data-tone=error]`。数字框 112 宽、右对齐、等宽数字、单位写在框内（`.ui-affix`）。前后可放 14px 图标（搜索、清空） | `st-input`、`mp-search`、`sb-search`、`tg-preset-input` |
| Select `.ui-select` | 就是 Field + 右侧 chevron；展开的列表是 Menu（选择菜单） | `dd-trigger`、`tspi-pf-pick` |
| Textarea `.ui-textarea` | 同 Field 的框，`resize: vertical` | 原生 textarea |
| Switch `.ui-switch` | 36×20，关 `--border-strong`（两套主题都看得见），开 `--accent`。被系统强制打开的：禁用的开 + 旁边一个徽标说明原因 | `st-switch`、`tspi-pf-sw` |
| Checkbox / Radio `.ui-check` `.ui-radio` | 16px，1.5px `--border-strong`；选中 `--accent` 底；ask 门单选题用单选圈、多选题用勾选框 | 原生勾选框；ask 门没有标记的行 |
| Segmented `.ui-seg` | **设一个值**。外框 `--bg-active` 底，选中块 `--control-on`（新 token：浅色白、深色 `#2b2931`）+ `--shadow-1`。≤4 个短选项用它，更多用 Select；**由选项个数决定，不由语言或宽度决定** | 9 种分段 / 标签里设值的那些 |
| Tabs `.ui-tabs` | **切一个视图**。文字标签 + 当前项 2px `--text` 下划线，标签可带计数 | 会话信息、文件面板、记忆的"查看"、ask 多题、旁路提问话题、omp picker / prefs 的标签 |
| Badge `.ui-badge` | 18 高、`--radius-sm`、11px；中性 / accent / success / warning / error 五种色，可带圆点。状态、范围、来源、"推荐""默认"都用它 | "通过环境变量或配置使用"整句绿字、"进行中""运行中"紫字 |
| Menu `.ui-menu` | `--bg-overlay` + `--shadow-2` + `--radius-lg`，项高 32。第一列 16px：动作菜单放图标，选择菜单放 ✓（**当前项只靠 ✓**，灰底只表示悬停）；破坏性项红字、放最后、前面分隔线；不可用项灰字，原因写在第二行小字；小节标题 11px `--text-3` | 6 种菜单 |
| Popover `.ui-pop` | 宽 300（最小 280），标题 13px 粗、正文 `--text-2`、按钮 sm 右对齐 | 审批 / 全自动确认、结束子代理的行内确认 |

| Notice `.ui-notice` | spec 现有的内联错误条，加 info（`--accent-soft`）变体；最多一个动作 | 插件"重新加载"提示条等 |
| Toast | 规格不变（spec §4.23）；**层级低于菜单、浮层、对话框** | 修 2.1 第 3 条 |
| Chip `.ui-chip` | 输入框工具条专用：28 高胶囊，**无底色**，悬停 / 打开时 `--bg-hover`；审批胶囊写出模式名，全自动用 `--st-waiting-text` | 工具条上四种底 |
| Kbd / Disclosure / Tooltip | Kbd 照旧；展开一律 chevron 旋转 90°；Tooltip 照旧 | 原生 `▶ details` |

新增 token（三处主题块都要加）：`--control-on`、`--text-on-danger`（浅色白、深色 `#0c0b0e`；深色的 `--st-error` 是浅红，白字对比度不够）。

**通则**（2026-10-22 仓库所有者同意，写在 `controls.css` 开头）：

| 规则 | 做法 | 范围 |
|---|---|---|
| 输入框聚焦不画外描边 | 边框隐去，换成两层阴影：`0 0 0 1px var(--accent)` + `0 0 0 4px var(--accent-soft)`；错误态用 `--st-error` / `--st-error-soft`。同时写 `outline: 2px solid transparent`：Windows 高对比度模式（`forced-colors`）会清掉 `box-shadow`、把 outline 和边框换成系统色，只靠阴影时那里看不到焦点。现在整个渲染进程没有处理 `forced-colors`，这条是唯一的兜底 | Field、Select、Textarea；按钮、菜单项、开关等键盘焦点不变，仍是全局 `:focus-visible` 的 2px 外描边 |
| 句子里的图标下移 0.125em | `vertical-align: -0.125em`，图标宽高 1em（`.ui-icon-inline`）；设置行标签改成普通文字块，ⓘ 跟在最后一个字后面（英文标签折两行时不漂到列尾） | 只给夹在文字里的图标：链接后的 ↗、标签后的 ⓘ、说明里的状态图标。按钮、菜单项、胶囊里的图标放在 `align-items: center` 的 flex 里，`vertical-align` 不起作用，不加 |
| 多行文字 `text-wrap: pretty`，短标题 `balance` | `pretty`：`.ui-help`、`.ui-menu-note`、`.ui-pop-body`、`.ui-dialog-desc`、`.ui-section-note`、`.ui-notice`；`balance`：`.ui-pop-title`、`.ui-dialog-title` | 对话流正文属于过程区，不动 |

同一轮看过、没有采纳的（来源是一份外部的界面约束清单）：

- 不用 `#000`、背景靠 1-3% 明度分层：已经是这样。各层 L\* 浅色 93.9 / 95.3 / 97.7 / 100，深色 3.2 / 4.1 / 5.3 / 8.0 / 10.7；`#000` 只出现在 `tsp.css` 的渐隐遮罩里（只取透明度）。
- 数字 `tabular-nums`、折叠用 `grid-template-rows: 0fr -> 1fr`：已经在用（约 60 处；`ui/Reveal.tsx` + `motion.css` 的 `.reveal`）。剩下的原生 `<details>` 在本节表里已经换成 Disclosure + `Reveal`。
- 深色主题字重统一降 40：中文回退的微软雅黑 UI 只有 400 / 700 两档，按 CSS 的字重匹配 360 仍取 400、560 仍取 700，变细的只有 Geist 的拉丁字母，同一行中英文粗细不一；`body` 也没有设 `font-weight: var(--fw-regular)`，只改 token 不生效。要试只在英文界面降 20-30，截图对比后再定。
- 流式文字逐字 `blur(6px)` 渐显、字间隔 30ms：在过程区里（不在本次范围）；字间隔 30ms 等于每秒最多约 33 个字，模型吐字比这快，显示会越积越慢；逐字包元素会影响选中复制、Markdown 渲染和 omp 整段替换文本，几百个元素同时做滤镜在滚动时掉帧。

## 4. 设置页（替换 spec §4.19 的版式部分）

样张 `3.2/settings.html`；对比图 `screenshots/ui-design/compare-settings-*.png`。

1. **设置导航占侧栏的位置**：进设置时侧栏换成设置导航（顶上 `‹ 返回任务  Esc`、搜索全部设置、10 节），退出时换回会话列表。内容从 x≈465 提到 x≈281，内容列仍然最大 880、左对齐。窗口窄到侧栏变抽屉时，导航变成内容顶上的一个下拉（`通用 ▾`），不再折成两行药丸。
2. **行**：最小 40 高，控件一律 sm（28），标签列 200，ⓘ 紧贴标签文字（不漂到列尾）；改过的值左侧竖线 + 控件后"恢复默认"图标（悬停提示写默认值）。
3. **控件怎么选**：布尔 → 开关；枚举 ≤4 → 分段，更多 → 下拉（两种语言一致）；数字 → 112 宽数字框，单位从 key 后缀推（`Ms` → ms、`Seconds` → 秒、`Percent` → %），标签里不再写"（毫秒）"；`-1` / `0` 这类特殊值按该键的说明写成占位文字，没有说明的照原值；字符串数组（如 `task.disabledAgents`）→ 标签输入；对象 / 其余 JSON → "编辑…"按钮 + 等宽摘要，点开对话框编辑并校验，页面上不再铺裸 JSON 文本框。
4. **高级**：页内左侧目录（8 个分组 + 当前分组下的前缀小组，带个数），右侧是选中分组的行，**全部平铺、没有折叠**；前缀做小标题（`服务商 providers.*  20 项 · 1 项改过`），行里的 key 去掉前缀，不再被截；枚举值原样用等宽字显示（omp 的取值），不再中英混排。搜索仍在导航顶上，覆盖全部设置。
5. **管理列表**（提供商、自定义提供商、MCP、SSH、插件、市场）：全部用列表行；状态用徽标；同一类动作同一种按钮；删除 / 移除 / 卸载收进 ⋯ 菜单。添加和编辑的表单改成对话框（标签在上的竖排字段），不再在列表里展开 112 宽标签列的表单。
6. **提供商与账号**：分"已连接""自定义提供商"两组；没连接的 84 个不铺开，页头"连接提供商…"打开一个可搜索的选择对话框，选中后走现有的登录 / 填 key 流程。
7. **各节**：通用——快捷键两列；工具与权限——工具网格每格一样（名称 + 状态徽标 + 有对应设置项的才有开关），去掉自相矛盾的"可用，当前没启用"文字；上下文与记忆——记忆的"统计 / 诊断 / 待整理 / 注入内容"是标签页，"清空"是分组标题右侧的 `danger` sm 按钮；集成、插件——"范围"下拉放页头右侧；关于——每个版本一行（名称、版本号、一个"检查更新"）；一页最多一个主按钮。
