## 1. 范围：只改外观，不改功能

- 不增删任何操作、快捷键、菜单项、设置项、IPC、数据；能点的东西点了还是做同一件事，信息不减少（被收进悬停提示的要写明）。
- 改的只有：颜色、尺寸、圆角、排列、图标形状、文字样式。
- 端到端测试里检查行为的断言不改；只因为元素换了样子才失败的选择器跟着改。
- 这次不动的界面：顶栏（像素标志已经换过）、新任务页、过程区（工具卡默认展开，2026-10-20 刚定）、门、模型选择对话框、用量对话框、设置页、评审、终端、命令面板、托盘。

## 2. 色板和 token

### 2.1 主色换鸢尾紫（仓库所有者 2026-10-20 定）

2.6 选松石绿时还没有标志；现在的像素 π 是 粉 → 紫 → 蓝 渐变，松石绿不在里面，标志和界面像两套东西。主色取 π 中段的鸢尾紫（候选色板的生成脚本是同一目录下的 `palette.mjs`，已删除，见上）。不用 iOS 系统蓝和毛玻璃。

- **主色**用法不变（进行中、焦点环、链接、上下文圆环、开关、选中），只换值。
- **灰阶跟着换色相**：所有带色相的灰（表面、线、文字、遮罩、阴影色）色相从绿 155° 换成紫 255°，HSL 的饱和度和亮度不变，所以层级和对比度基本不变。
- **"新增"单独用绿**：现在 `--diff-add-*` 直接用主色；换紫以后 `+` 会变紫，不像新增。改成独立的绿。

### 3.2 侧栏任务行：状态点和选中样式（D）

状态槽仍是 16×16，标题对齐不变；图标换成 8px 的点。仓库所有者 2026-10-20 定：**已完成、进行中、需要你介入（审批 / 回答问题）、失败四种状态各有各的样子**，形状 + 颜色双信号：

| 状态 | 什么时候 | 现在 | 改成 |
|---|---|---|---|
| 进行中 | `running` / `starting` | 14px 转圈 | 实心圆点 `--st-running`，外圈 3px `--accent-soft` 光晕；光晕按 `--dur-breathe` 呼吸，减少动效时静止 |
| 需要你介入 | `needs_you` | 圆圈感叹号 | 菱形（8px 方块转 45°，圆角 1px）`--st-waiting` |
| 已完成 | 空闲且最后一轮正常结束（`lastTurn.status === "completed"`） | 只在**未读**时画对勾，看过就消失 | 空心圆 1.5px `--st-done`，**看过也一直在**；未读仍靠标题用 `--text`（和现在一样）区分 |
| 失败 | `error`，或空闲且最后一轮出错 | 圆圈叉号 | 实心圆点 `--st-error`，无光晕；照旧保持到这个任务开始新一轮 |
| 其它 | 从没跑过、最后一轮被停止 | 不画 | 不画（被停止的照旧在行尾写"已停止"） |

`aria-label`（运行中 / 有子代理在跑 / 等你确认 / 完成 / 出错）照旧。"已完成"看过也画，是这次唯一改了判断条件的地方：`shared/ui/sidebar-model.ts` 的 `dotKind`，原来 `unread` 才算 `done`，改成"空闲且最后一轮 `completed`"（单测跟着改）。

### 3.4 改动卡片：文件图标 + 行数条（D + B）

折叠箭头、`打开评审`、`⋯` 菜单（复制文件列表）、点文件打开、右键 / 行尾悬停出现的"在资源管理器中显示"按钮、超过 5 个文件折成"还有 N 个"，这些都不变。左边新加的文件图标只是装饰，不能点。

| | 现在 | 改成 |
|---|---|---|
| 外框 | `--radius-lg`，1px `--border` | `--radius-xl`，1px `--border-subtle` |
| 头 | `N 个文件已更改 +48 −6` + 右边按钮 | 同样的内容；标题 `--fw-strong`；`打开评审` 改成 26 高、1px `--border` 的描边按钮 |

**行数条**（照 `git diff --stat`）：每行最多 24 个字符，`+` 用 `--diff-add-fg`、`−` 用 `--diff-del-fg`，`--font-mono` `--fs-code-sm`，左对齐成一列。一张卡里改动最多的文件不超过 24 行时一行一个字符；超过时整张卡按同一比例缩小，不为 0 的一边至少留 1 个字符。条只是看比例，`aria-hidden`。行数未知（二进制文件等）时数字和条都不画，和现在一样。

### 3.5 输入框上方的状态行：两个按钮

| 按钮 | 什么时候出现 | 样子 | 点开 |

| `后台任务` | 本会话有过 `bash` 后台任务 | 高 24，`--radius-md`，1px `--border`，`--bg-raised`；13px 终端图标（`--text-2`）+ 文字 `--fs-xs` + 计数 | 和现在同一个看板，只列 bash 任务 |
| `子代理` | 本会话有过 `task` 派出的子代理 | 同上，图标是两个人 | 同一个看板，只列子代理（展开就是现在的 `SubagentDetailPanel`） |

计数：有在跑的显示 `● N`（`--st-running` 点 + 数字，600 等宽）；都结束了显示 `✓ N`（`--text-3`）；有失败的照现在的规则标红。悬停提示和 `aria-label` 写全"N 个运行中，M 个已结束"。看板里每一行、展开后的内容、Esc 关闭并还焦点，都和现在一样。
