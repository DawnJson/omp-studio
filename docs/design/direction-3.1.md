## 1. Tern 里 omp 的样子(观察)

### 1.1 过程区:一个工具一个块,结果直接摆出来

- **工具头**:一行 = 图标 + **工具名**(`--text`,600)+ 目标(文件名/模式/命令,`--text-2`,等宽)+ 右侧数字(`4 files in .`、耗时),右侧数字 `--text-3` 等宽。没有底色,没有折叠箭头。
- **Read / Glob**:头下面一排文件胶囊(文件图标 + 目录淡色 + 文件名正常色,等宽,浅底圆角),不显示内容。
- **Grep**:按文件分组,每组一个文件头胶囊(带命中数),下面是带行号的命中行,命中行左侧一条竖线;整块最多若干行,超出部分**底部渐隐**,下面一行小字 `3 more lines · Show all`。
- **Bash**:圆角卡片(`--bg-raised` + 1px 边)。上:命令(等宽);中:输出只留最后几行,上面一行 `10 earlier lines ⌃` 可展开,最上一行被渐隐;下:状态脚 `✓ Done 0.6s` / `● Running 6.0s`(运行中是强调色点 + 实时秒数)。
- **Task**:头 `Task  2 agents  [background]` + 右侧耗时;下面 `waiting on 1 of 2 jobs  1 done`;再下面是**子代理并排小卡**(两列网格),每张卡 = 状态点(运行中实心点、完成 ✓)+ 名字 + 右侧耗时;完成后变成 `1 job settled  1 done` + 一张折叠卡。
- **Todo**:头 `Todo 0/6`;下面按阶段分组,阶段行 = 状态环 + 阶段名 + 右侧 `0/2`;阶段下是任务行(空心圆 / 进行中带点的圆 / 完成)。全部完成后只剩阶段行。
- **Ask**:提问时问题卡**替换输入框**(问题、选项带说明、`Recommended` 标、当前项左侧竖条 + 底色、最下方是当前选项的预览、底部 `Hide / Note / Skip / Submit`);回答后在对话流里留一块:`Ask 问题`,下面列全部选项,选中的那项带 ✓。
- **一轮结束**:最后一行是斜体小字的 recap(时钟图标 + 一句话),输入框上方状态行变成 `32.4s · 19K tok · <$0.01 this turn`(悬停给出 `This turn: 32.4s · 19,156 tokens (15,450 in · 3,706 out) · <$0.01`)。

### 1.2 输入框上方的状态行

左:计时(`1m 15s`)+ 当前在做什么(`Running full test suite once`);右:当前 todo 项 + 进度 `0/6`(全部完成时 `All done 6/6`);再上面一条 1px 的上下文进度线,两端小字 `2%` 和 `1M`。子代理/后台任务在运行时右上角两个小徽标(`👥2`、`⚡2`),点开分别是子代理面板(表格:成本/时间/请求/工具/token,右边是选中子代理的任务全文)和后台任务面板。

### 1.3 模型选择

- 居中大对话框,标题行 = 图标 + `Switch model` + 搜索框(占满)+ 右侧总数 `218`(搜索时 `17 of 218`)。
- 主体是**一张表**:列 = 模型(provider 淡色 / 模型名正常色,等宽)+ 角色胶囊(`default`、`smol`、`slow`、`plan`)| `Int` | `t/s` | `Ctx` | `$/M`;数字列右对齐等宽,`--text-2`。
- 分组:无搜索时 `Recent 21` 在前、`All 197` 在后;搜索时 `Recent 2` + `Matches 15`。当前模型行底色高亮 + 右侧 ✓。
- 输入 `@` 列出角色(`@smol`、`@default`、`@slow`),每个角色带它绑定的模型和数字,按钮变成 `Apply role`。
- 底部一行是选中模型的参数:`ctx 1m · out 393k · price $0.3/1.2 per M · reasoning yes` + 胶囊 `current` `default`;最下一行左 `Task model`,右 `Close` + 主按钮 `Use for session`。

### 1.4 其他弹层

上下文是一张卡:大号 `18K of 1M tokens · 2%`,一条分段进度条,下面每类一行(色块 + 名称 + token + 百分比)。斜杠菜单是浮在输入框上方的列表:命令名等宽 + 说明 + 右侧当前值。

## 2. omp-studio 这次改的

| # | 部位 | 现在 | 改成(照 Tern) |
|---|---|---|---|
| 1 | 工具行 | 一行小字(图标 + 名 + 参数 + 耗时),输出在下面灰块里 | §1.1 的工具头;名 `--fs-sm` 600 `--text`,目标 `--font-mono` `--fs-xs` `--text-2`,右侧数字 `--text-3` |
| 2 | Read/Glob/Grep | 参数一行 | Read/Glob:文件胶囊一排(点开 = 现有的文件预览);Grep:按文件分组的命中行,超出渐隐 + `N more lines · Show all` |
| 3 | Bash | 灰块全文 | 卡片:命令(最多 6 行)/ 只显示最后 8 行 + `更早的 N 行`(英文 `N earlier lines`)展开 / 状态脚 `✓ 完成 0.6s`、`● 运行中 6.0s`、`✕ 退出码 1`;用户的 `!命令`(`ShellBlock`)用同一张卡 |
| 4 | 显示不全的块 | 硬截断或滚动 | 统一组件 `Clamp`:最多 N 行,超出时 `mask-image` 把底部两行渐隐到透明(不依赖底色),下面一行 `N more lines · Show all`(中文 `还有 N 行 · 全部显示`),展开后变 `收起`,最多长到 40 行、更长的块内滚动 |
| 5 | Task / 子代理 | 结果全文的灰块 | 头 `Task 2 个代理 [后台]`;状态行 `等待 2 个中的 1 个  1 完成`(都结束后 `2 个已结束  2 完成`);子代理两列小卡(状态点 + 名字 + 耗时),点卡在卡片下方就地展开现有的 `SubagentDetailPanel`,再点收起;`wait` 工具同样画小卡 |
| 6 | Todo | 只在输入框上方的看板 | 对话流里的 todo 工具调用画成 §1.1 的分组清单(阶段 + 计数) |
| 7 | Ask 回答后 | 一行 | 问题 + 全部选项,选中的带 ✓ |
| 8 | 一轮结束 | 没有 | 结论下方一行小字:`32.4s · 19K tokens · $0.01`(`--fs-xs` `--text-3` 等宽;tokens = 本轮输入 + 输出,不含缓存;不足一分写 `<$0.01`;为 0 的段省略;悬停给 `输入 / 输出 / 缓存` 明细);运行中不显示 |
| 9 | 公式 | 原样显示 `$...$` | KaTeX 渲染 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`(块级居中);`$` 按 pandoc 规则(`$5 and $10` 不算公式);流式中未闭合的公式先按文字显示;KaTeX 解析失败时显示原文,`--st-error` 色 |
| 10 | 模型选择 | 左分组树 + 右详情两栏 | §1.3 的单表对话框:搜索 + `常用` / `全部`(搜索时 `匹配`)+ 数字列(智能分 / 速度 / 上下文 / 价格,没有数据显示 `–`)+ 底部参数行 + `用于此任务`;`@` 列角色。角色页签在表上方,思考强度、快速 / 慢速模式、添加提供商在表下方的控件行和操作行 |
| 11 | 审批菜单 | 留白多、当前项打勾 | 和语言/主题菜单同一种:紧凑行,当前项用 `--bg-active` 底色,不打勾 |
| 12 | 关于 | 名称 + 版本 + 一句话 + 反馈 | 加:omp 版本和路径、Electron / Chromium / Node 版本、许可、复制版本信息按钮 |
| 13 | 标题栏三键 | 弹窗打开时瞬间变暗,遮罩是渐变 | 三键颜色按遮罩淡入的时长和曲线渐变(140ms `--ease-out`,主进程分帧插值 `setTitleBarOverlay`;系统开了减少动画时 100ms);恢复用同一组参数;切换主题时立即换色 |
| 14 | 侧栏任务标题里的 emoji | 显示成方框 | 字体栈加 `Segoe UI Emoji`(Windows)/ `Apple Color Emoji` / `Noto Color Emoji` |

不改:输入框的形状和控件(3.0 刚定)、侧栏结构、改动卡片、门、数据和 IPC。Tern 的 recap 句子、输入框上方的子代理/任务徽标:studio 已有对应物(结论、`JobsBoard` 两个按钮),不重复做。
