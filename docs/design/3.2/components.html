开关 · 勾选框 · 单选 .ui-switch .ui-check .ui-radio

只有一种开关（36×20，关=--border-strong，开=--accent）。系统强制打开的项不画成"淡紫色的开"，而是禁用的开 + 一个说明徽标。所有原生勾选框换成 .ui-check。Ask 门：单选题用单选圈，多选题用勾选框，一眼分得出。

分段 · 标签页 .ui-seg .ui-tabs

分段 = 设一个值（≤4 个短选项，超过就用下拉；由选项个数决定，不由语言或宽度决定）。标签页 = 切换同一容器里的视图。药丸形标签、带框的预设标签、纯文字加框的思考强度都并进这两种。

菜单 · 浮层 .ui-menu .ui-pop

第一列 16px：动作菜单放图标，选择菜单放 ✓（当前项只靠 ✓ 表示，不靠灰底，灰底只是悬停）。破坏性项红字、放最后、前面一条分隔线；不可用项灰字，原因写在第二行。浮层最小宽 280，按钮右对齐。

对话框 .ui-dialog

只有一种外壳：标题 17px + 可选一句说明，右上角 ×；正文竖排字段（标签在上）；页脚按钮右对齐，取消在前、确认在后，附带选项放页脚左侧。确认框就是 sm 宽的同一外壳；破坏性确认用红底确认键，打开时焦点在"取消"。不叠对话框（会话信息里不再打开分享对话框）。
