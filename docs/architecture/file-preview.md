# 文件预览与右键菜单

文件面板、对话中的文件链接和本地图片共用主进程的文件分类、大小限制与实际路径校验；界面见 [spec 4.27](../design/spec/4.27-file-preview-pane.md)。

## 工作区读取

`file-handlers.ts` 按 `ProjectFilesTarget` 查任务、项目或默认文件夹。相对路径和明确指定的额外根只在当前根内解析。任务文件的绝对链接未指定额外根时，在任务目录和已加入的工作区目录中匹配；返回的 `PreviewFile.root` 供后续打开、定位使用。

自动匹配额外根后，界面保留原绝对路径用于打开和定位。主进程只把仍在当前所选根内的绝对路径换为相对路径，再经 `resolveInsideReal` 检查，目录移除、下标重用时不能打开另一目录的同名文件。

## 文件链接直接预览

主窗口的显式文件预览入口调用 `readLinkedPreviewFile(taskId, path)`，直接预览链接指向的本机文件，包括任务工作区以外的文件；不显示授权或文件选择框（所有者定，2026-11-14）。这个接口允许主窗口请求读取目录外的单个本机文件，主进程不把渲染进程的调用视为可验证的用户点击。

- 任务必须存在；相对路径按任务目录解析。先走工作区读取，只有路径在工作区外才按父目录和文件名读取单个本机文件；工作区内的符号链接越界仍拒绝。
- 请求路径和解析后的实际路径均拒绝网络、设备、盘符相对路径和 NUL。文件读取沿用实际路径检查、分类和大小限制。
- 返回路径始终是解析后的绝对路径；已加入的根保留 `root`，目录外内容标记 `external: true`、`canOpen: false`。不加入工作区、不枚举父目录、不保存授权缓存，预览工具栏不提供目录外文件的系统默认打开和定位。切换文件或关闭面板时忽略旧的异步结果。
- 原 `readPreviewFile`、`listDirectory` 和自动本地图片读取仍限制在工作区内。显式预览允许读取目录外单文件，不给 agent 新增工作区，也不自动读取兄弟文件或邻近资源。
- HTML 继续使用原有隔离协议与 sandbox，Markdown/HTML 不能借预览读取旁边的资源。

文件树缓存按任务和根下标保存；普通界面移除目录或 `/remove-dir` 会重置所选根。若 omp 独立重排目录、但根下标未变，文件树可能需要手动刷新。

## 文件右键菜单

文件树中的文件/目录，以及对话中的本地文件链接使用同一个原生菜单，仅包含“复制路径”和“在文件管理器中打开”（所有者定，2026-11-14）。

`showFileContextMenu` 按目标目录解析本机路径。右键本身不读取内容；用户选菜单项后，复制完整路径，或用 `showItemInFolder` 在系统文件管理器中定位文件/目录，不执行默认关联程序，也不枚举或预览目录内容。

验证覆盖 `test/file-preview-actions.test.ts`、`test/workspace-dirs-roots.test.ts`、`test/task-file-path.test.ts` 和文件面板/预览的 e2e。原生菜单弹出及 Explorer 在 e2e 中替换为受控实现，保留真实 IPC、文件读取、菜单回调和剪贴板。
