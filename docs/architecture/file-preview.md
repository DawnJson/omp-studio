# 文件预览与右键菜单

文件面板、对话中的文件链接和本地图片共用主进程的文件分类、大小限制与实际路径校验；界面见 [spec 4.27](../design/spec/4.27-file-preview-pane.md)。

## 工作区读取

`file-handlers.ts` 按 `ProjectFilesTarget` 查任务、项目或默认文件夹。相对路径和明确指定的额外根只在当前根内解析。任务文件的绝对链接未指定额外根时，在任务目录和已加入的工作区目录中匹配；返回的 `PreviewFile.root` 供后续打开、定位使用。

自动匹配额外根后，界面保留原绝对路径用于打开和定位。主进程只把仍在当前所选根内的绝对路径换为相对路径，再经 `resolveInsideReal` 检查，目录移除、下标重用时不能打开另一目录的同名文件。

## 目录外单文件预览

目录外文件经用户单独选择后，仅允许本次预览，不加入工作区（所有者定，2026-11-14）。

- 原读取接口仍拒绝未授权路径；预览区显示“允许预览…”按钮，自动图片加载不会弹授权。
- `choosePreviewFile` 只以请求路径作为系统文件选择框的默认位置；只读取用户实际选中的那个文件，取消返回 `null`。
- 请求路径、选择结果和解析后的实际路径均拒绝网络、设备等非本机路径。文件读取沿用父目录内的实际路径检查、分类和大小限制。
- 返回内容快照，不保留授权或目录缓存；不授予系统默认打开、定位、读取兄弟文件或给 agent 新增工作区的权限。切换文件或关闭面板时忽略旧的异步结果。
- HTML 继续使用原有隔离协议与 sandbox，Markdown/HTML 不能借单文件授权读取旁边的资源。

## 文件右键菜单

文件树中的文件/目录，以及对话中的本地文件链接使用同一个原生菜单，仅包含“复制路径”和“在文件管理器中打开”（所有者定，2026-11-14）。

`showFileContextMenu` 按目标目录解析本机路径。右键本身不读取内容；用户选菜单项后，复制完整路径，或用 `showItemInFolder` 在系统文件管理器中定位文件/目录，不执行默认关联程序。菜单操作不授予预览读取权限。

验证覆盖 `test/file-preview-authorization.test.ts`、`test/workspace-dirs-roots.test.ts`、`test/task-file-path.test.ts` 和文件面板/预览的 e2e。原生文件框、菜单弹出及 Explorer 在 e2e 中替换为受控实现，保留真实 IPC、文件读取、菜单回调和剪贴板。
